# R2 两级候选评估报告

> 候选批次：`r2v2_20260711_031617`  
> 本批只生成候选，不覆盖现有预警事件。

## 规则

- R2W：近两学期不同且尚未通过的课程恰好 2 门，警告；
- R2：近两学期不同且尚未通过的课程不少于 3 门，严重；
- 两条规则互斥，同一学生不会重复命中。

## 结果

| 项目 | 学生数 |
|---|---:|
| R2W 警告 | 1,032 |
| R2 严重 | 212 |
| 新口径合计 | 1,244 |
| 旧 R2 | 1,190 |
| 旧 R2 且新口径仍命中 | 694 |
| 旧 R2 不再命中 | 496 |
| 新口径新增关注 | 550 |

总规模接近，但人群构成变化明显。原因是旧规则按失败记录累计，新规则按尚未解决的不同课程计算。

## 已落地

- `sys_alert_rule` 已增加 R2W，规则总数由 5 条变为 6 条；
- R2、R2W、R4、R6 的配置文案已与新算法一致；
- `alert_rule_candidate` 保存候选批次，可供差异预览；
- 现有 `fact_alert`、`alert_event`、责任人、跟进记录和状态历史均未覆盖。

## 启用建议

1. 对 496 名不再命中的旧事件标记“规则升级后待复核”，不直接删除；
2. 对仍命中的 694 名学生保留原事件和处理状态，仅更新规则版本；
3. 对新增 550 名学生创建新事件，其中 2 门为警告、3 门及以上为严重；
4. 在预警页面增加规则版本和迁移批次标识；
5. 管理员确认候选差异后再正式切换。
