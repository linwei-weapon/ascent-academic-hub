# 数据核对清单（管理端展示视角）

> 拿这份去和教务处/源系统核对。读法：**管理端要展示什么 → 需要什么数据（成品/或原料）→ 没有的话影响哪些地方**。
> 最后更新 2026-06-24。关联：`逐页规格书.md`(每页详情) · `指标血缘表.md`(口径) · `技术方案.md`。

## 怎么用这份清单
- 每行 = 管理端上**一块要展示的内容**（用大白话+页面位置写）。
- **所需数据**列给对方两条路，方便对方回答：
  - **成品**：有没有现成的统计/报表/接口（有就要个口径参考）。
  - **或原料(更想要)**：能算出这块内容的**底层明细数据**。⭐我们自建分析库做ETL、不直连教务系统，**现成接口我们调不到，原料才是我们真正要的**——拿来自己按任意维度算+下钻。
  - **都没有→对策**：写明降级/模拟方案。
  - 例：毕业率 = 成品(有无按学院的毕业率统计) / 或原料(往届各届学生名单+毕业标记+学位标记) / 都没有→模拟。
- **现状**：🟢已确认有(放心) · 🟡有但要加工 · 🔴可能没有(**重点核对**)。
- **影响范围**：这块数据若缺失/结构不符，会波及哪些页面、怎么降级。
- **核对结论**：你填 ✅有 / ❌没有 / ⚠️部分，加一句备注。

> 🟢 项基本不用问（列出让你心里有底），**真正要花时间核对的是 🔴 和 🟡**。
> 已决定隐藏的"学校管理/数据同步"两页不在本清单内。

> 📸 每节末尾附了对应**管理端页面截图**（当前为原型效果，数据多为演示值），方便对方对照"这块展示长什么样→需要什么数据"。截图存于 `页面截图/` 目录。

## 建议优先核对的 TOP（投入产出最高）

1. **🔴「是否还有清单外没给我的数据文件」**——最该先问。一旦有教职工表/调停课表/往届毕业数据，下面一批🔴能直接从"模拟"翻"真实"。
2. **🔴 §6 教职工名单（原料）**：学历/年龄/教龄/毕业院校——决定师资页是大面积真实还是大面积模拟。
