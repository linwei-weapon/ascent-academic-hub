## 表1. 成绩数据（核心事实表，18.6万行）

30 列：`学期 / 学号 / 姓名 / 年级 / 管理部门 / 专业 / 行政班 / 课程代码 / 课程名称 / 被替代课程代码 / 被替代课程名称 / 教学班代码 / 教学班名称 / 周学时 / 学分 / 是否必修 / 教师 / 是否重修 / 是否及格重修 / 得分 / 等级 / 绩点 / 是否通过 / 发布状态 / 总评成绩 / 补考成绩 / 缓考成绩 / 加分成绩 / 补考标记 / 备注`

**关键字段与枚举**：
- `是否通过`：通过=178,834 / 未通过=7,235 / 空=378 → **挂科率≈3.9%**。挂科口径直接用此列。
- `得分`：0~100，386 个非数值（缺考/等级制）；及格线 60 处明显断层。
- `等级`：15.7万为空(数字制) / 2.8万为等级制(通过·优秀·良好·中等·不通过·合格)。**口径需兼容数字制+等级制**。
- `绩点`：已算好(如 4.3)，GPA 直接用。
- `是否必修`：必修148,497 / 选修37,946。
- `是否重修`：正常183,784 / 重修2,663。
- 教师列格式：`李**(2061)`，含脱敏姓名+工号；可多教师 `A(1);B(2)`。
- 学期分布：2022-2023最密(4万/学期)；**2025-2026-1 有 3,156 行真实数据**（最新学期演示基底）。

## 表3. 教学任务（维表 + 师资/教室金矿，1,528行 × 52列）

含金量最高，补齐了多个"以为没数据"的指标：
- 课程维度：课程代码/名称/**学分**/课程类别/课程性质/是否必修/考核方式/授课语言/先修课程。

- 组织：开课部门/授课校区/上课年级/上课专业院系/上课专业/上课行政班。

## 表5/6. 培养方案 docx（培养质量分析金矿）

每份 = 15 段落 + 1 张计划课程大表(307~322行 × 18列)。结构：
- **培养目标**（一段文字）
- **修读要求**：必修/选修/实践学分 + 最低总学分 + 学位要求（安全工程 116/22/28/166；海洋油气 101.5/35/28/164.5）
- **毕业生应获得的知识和能力**：12 条（工程知识/问题分析/设计开发/研究/使用工具/工程与社会/环境与可持续/职业规范/个人与团队/沟通/项目管理/终身学习）→ **对应工程认证"毕业要求"，直接喂 `GraduateRequirements.vue`**
- **计划课程表**(18列)：课程模块/课程代码/课程名称/课程性质/学分/总学时/理论/实验/实践学时…，★核心课程 ▲实践环节
- **用途**：培养方案完成度 = 学生已修课程(成绩表) ∩ 计划课程(docx) → 算完成率。`CourseObjectives`/`GraduateRequirements`/培养质量页有据可依。
- ⚠️ 仅 2 个专业有方案 docx（安全工程、海洋油气），其余 27 专业无 → 记入血缘表缺口（其余专业方案完成度需降级或模拟）。
