# 04 · 使用手册

## 1. 登录与工作身份

访问 `http://localhost:3006/`。原型演示账号统一使用密码 `Demo@2026`。

推荐账号：

| 用户名 | 角色 | 范围 |
|---|---|---|
| dean | 教务处处长/系统管理员 | 全校＋系统管理 |
| school_leader | 校领导 | 全校 |
| college_dean | 二级学院院长 | 本学院明细＋他院聚合 |
| college_secretary | 二级学院教学秘书 | 本学院 |
| counselor | 辅导员 | 已绑定行政班 |
| dept_director | 系主任 | 已绑定专业 |

`admin` 仅作为兼容管理员账号，密码同为 `Demo@2026`；历史弱密码 `admin123` 已停用。

右上角显示当前工作身份、详细数据范围和学期。一人多角色时切换身份会重新加载菜单、范围和
AI会话，旧范围不能继续使用。

## 2. 菜单与典型路径

### 教学管理分析

- 教学数据总览：从全校进入学院、专业、课程、学生名单和学生详情。
- 学业预警监控：查看当前风险、历史变化、规则配置和规则自发现；卡片筛选不整页刷新。
- 教学运行分析：课程总览、实际教室占用、调课、教师负荷和课程排课分析。
- 培养质量分析：学院—年级—专业—方案联动，查看方案结构、学生绑定和执行进度。
- 师资保障分析：查看师资结构、课程团队连续性、负荷和历史排课偏好。
- 学生成长与学业分析：查看 GPA 与挂科联合迁移、挂科模式、成长轨迹和学生档案。

表格中的“详情/核查”优先在当前页面打开抽屉。关闭后保留原筛选、分页和业务上下文。

### AI管理决策

- 管理要情：优先查看“本次新增/升级/扩大”的少量事件，再进入证据或继续研判。
- 决策研判：先选择推荐管理问题或管理专家，再用自然语言调整临时参数。

AI结果中的来源、数据时间、分析范围、版本、限制和证据入口必须同时阅读。AI建议不是审批
结论，也不会自动执行开班、排课、帮扶或教师评价。

### 系统管理

仅系统管理员可见：

1. 账号管理：账号、教职工号、工作身份和统一身份映射。
2. 角色与功能权限：菜单权限、页面动作权限和权限预览。
3. 菜单管理：两级菜单、排序、路由和授权角色。
4. 数据权限：组织范围、带班/带生关系及权限核验。
5. 指标与口径管理：公式、来源、粒度、版本、管理意义和页面引用。
6. 分析方案管理：管理专家版本、方案测试、发布、角色覆盖、停用和回滚。
7. 审计日志：登录、敏感读取、导出、权限、规则和AI操作。
8. 系统参数：学校、学期、模型接入、缓存和展示参数。

预警规则配置和规则自发现位于“学业预警监控”，不在系统参数中。

## 3. 筛选、比较与下钻

- 页面顶部显示筛选影响范围；未明确提交的联动条件不会制造含义歧义。
- 二级学院在指定页面可查看其他学院聚合比较，但看不到他院学生名单、学号和档案。
- 学期、学院、专业、课程和学生下钻始终继承当前授权范围。
- 清除局部条件应使用页面提供的“恢复全校/本院口径”“清除临时条件”或筛选清除按钮。

## 4. 导出与审计

导出仅包含当前工作身份已授权的数据。CSV 使用 UTF-8 BOM；打印型报告使用浏览器打印。
名单、详情、导出和AI研判会记录操作人、工作身份、对象、结果和时间，不记录 Token、密码或
请求正文。

## 5. 常见提示

- “数据加载/正在计算”：等待局部区域完成，不要重复点击。
- “证据不足/待核验”：当前数据只能形成核查线索，不能作为正式审核结论。
- “无权限”：返回上一级或切换合法工作身份；直接修改 URL 不能扩大范围。
- “无已保存分析方案”：先在决策研判中完成测试并保存方案。
