# 06 · 数据库表结构

> 分析库 `analytics.sqlite` 共 **33 张表**，命名前缀：`dim_`（维表）/ `fact_`（事实表）/
> `agg_`（预聚合）/ `sys_`（系统元数据）。权威定义见 `code/backend/etl/schema.sql`。
>
> 通用约定：
> - 所有业务表带 `source` 字段（`real`/`sim`），用于回溯，**前端不暴露**。
> - 业务事实/聚合表均带 `semester_id`，贯通 9 学期（2021-2022-2 ~ 2025-2026-2）。
> - 外键完整性由 ETL 校验把关，DB 层 `PRAGMA foreign_keys=OFF`（避免跨学期孤儿）。

| 表 | 主键 | 用途 |

## 五、合成业务事实表（8 张，source='sim'）

真实学业源缺失的业务域，由 `synth_business.py` / `extract_ts.py` 按真实学业数据派生，
固定种子可复现，前端不暴露 source。

| 表 | 说明 |
|---|---|
| fact_graduation | 毕业去向：已修/应修学分、是否毕业、是否授学位、毕业状态、就业去向 |
| fact_attrition | 学籍异动：休学/复学/退学/转专业 + 原因（**读真实 student_changes 派生**） |
| fact_discipline | 考纪：违纪/作弊 + 处分 |
| fact_exam_cert | 校外考试：CET4/CET6/计算机二级/三级（**读真实 external_exams 派生**） |
| fact_attend | 课堂出勤：出勤率、旷课>3 人数/占比、趋势 |
| fact_major_req | 培养方案学分要求（除 2 真方案外为合成；真方案标 real） |
| fact_teacher_profile | 师资画像：规范职称/学历/学位/年龄段/学缘/教龄（按真实职称派生） |
| fact_schedule_change | 调停课：调课/停课 + 原因/学时/受影响人数/审核（**读真实 course_changes 派生**） |

> 标注「读真实…派生」的 3 张（attrition/exam_cert/schedule_change）在 run_etl 步骤⑦用真实源
> 覆盖合成版（`source` 实际为 real）。

## 六、关键索引

```
fact_grade:  idx_grade_student / idx_grade_course_sem / idx_grade_semester / idx_grade_lesson(lesson_id,semester_id)
fact_lesson: idx_lesson_course / idx_lesson_teacher(teacher_id,semester_id)
fact_alert:  idx_alert_student / idx_alert_level_st(level,status)
合成表:       idx_grad_student / idx_grad_major / idx_attr_college / idx_examcert_stu / idx_attend_course /
             idx_schedchg_college / idx_schedchg_teacher
```

> 教师详情等重查询依赖 `idx_lesson_teacher` + `idx_grade_lesson` 复合索引（60s→0.14s）。
