# 培养方案修读合规检查第一批记录

## 本批目标

将“学业进度”从简单的累计学分展示，升级为按专业、年级和培养方案版本匹配的修读合规检查。

## 已完成

- 培养方案按 `major_id + grade` 精确匹配，不再把不同年级学生混入同一版本。
- 已修学分仅统计培养方案内且已通过的课程；方案外课程及学分单列。
- 必修缺口按未通过的必修课程逐门累计。
- 核心课缺口按方案 `is_core` 标记累计。
- 选修缺口按方案最低选修学分与已通过方案内选修学分计算。
- 总缺口统一为“必修缺口 + 选修缺口”，避免把核心课重复计入。
- 识别重复修读、方案外修读，并形成结构化合规问题列表。
- 页面新增合规状态、缺口构成、选修完成情况和问题明细。

## 当前判定边界

目前源数据没有独立、规范的课程性质字段，因此必修/选修仍根据培养方案模块名称是否包含“选修”推断；核心课使用方案 `is_core` 字段。页面已明确展示该口径，避免将推断结果误认为正式教务规则。

## 验证结果

- 前端生产构建通过。
- 后端服务已重启并加载最新实现。
- 自动化回归共 73 项，73 项通过、0 项失败。
- 新增专项校验：方案版本、精确适用学生数、总缺口公式、合规状态及问题结构。
