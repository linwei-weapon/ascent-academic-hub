# 规则影响试算实现记录

## 实现范围

规则变更草稿可调用生产 ETL 使用的同一套 `alert_engine` 执行内存试算。试算读取当前成绩、学生、课程、培养方案和生产规则，仅替换目标规则的拟调整参数，不写入 `fact_alert`。

## 输出指标

- 当前命中人数；
- 拟调整后的候选人数；
- 保留人数；
- 新增人数；
- 退出人数；
- 净变化人数；
- 试算人和试算时间。

试算结果持久化到变更单的 `impact_json`，供列表和审批过程查看。

## 流程约束

- 仅草稿状态可以试算。
- 未完成试算的变更单不能提交审核。
- 缺少有效试算结果的变更单不能发布。
- 试算不会改变当前规则、当前预警、事件或跟进记录。
