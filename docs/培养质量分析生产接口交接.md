# 培养质量分析生产接口交接

## 原型与生产边界

原型使用 Excel 方案课程明细和 Word 培养方案临时构建数据。生产系统应由教务系统 API 提供结构化培养方案，不依赖 Word COM、文档排版或文本识别。

原型已经验证的业务结构包括：方案版本、适用学生、培养目标、毕业要求、方案课程、模块最低学分、课程完成证据、开课供给和教师覆盖。

## 培养方案接口必需字段

- 方案唯一标识、名称、版本、状态、生效与失效日期。
- 适用年级、专业、专业方向、培养类型和学生类别。
- 毕业最低总学分、必修最低学分、选修最低学分、实践最低学分。
- 培养目标、毕业要求、指标点。
- 一级模块、子模块、课程组、必修/选修性质和最低要求学分。
- 方案课程、学分、建议修读学期、开课季节、核心课程标识。
- 多选一、限选、跨模块互斥、最低门数等课程组规则。
- 方案版本切换和学生方案适用规则。

## 课程执行与供给接口必需字段

- 学生选课记录及退选状态。
- 成绩发布状态、有效成绩、补考、重修、缓考和课程认定。
- 课程替代关系及审批状态。
- 教学任务、教学班类型、容量、已选人数、教师和排课结果。
- 重修班、跟班重修等资源类型及报名条件。
- 未来开课计划、预计容量和计划状态。
- 课程先修、并修、后续课程关系及规则版本。

## 关键口径

- 明确需处理：方案必修课存在明确未通过成绩。
- 到期待核验：建议修读学期已到，但缺少通过、认定或明确未通过证据；不能直接称为漏选。
- 课程完成率：已有通过或认定证据的方案课程门数除以方案课程总门数。
- 无开课证据：当前已接入教学任务中没有课程记录；不等同未来不开课。
- 单一教师覆盖：当前已接入教学任务中仅关联一名教师；用于连续性核查，不评价教师。
- 毕业要求达成度：只有取得指标点、课程支撑矩阵、评价环节、目标值和实际评价结果后才计算。

## 当前缺失且不得推断的数据

- 正式先修课程关系。
- 未来开课计划。
- 重修班类型、容量和报名条件。
- 毕业要求指标点及课程支撑矩阵。
- 课程目标评价环节和达成结果。

这些字段缺失时，原型只显示证据边界，不生成毕业、学位或教学质量结论。
