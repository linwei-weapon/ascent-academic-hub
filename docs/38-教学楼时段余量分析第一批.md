# 教学楼时段余量分析第一批

## 完成内容

- 新增教学楼时段余量接口。
- 支持按学期、星期、节次和教学楼筛选。
- 按楼栋、教室类型、星期和节次返回已用比例、剩余比例和状态。
- 将时段划分为“余量充足”“可协调”“紧张”。
- 页面新增时段余量表、星期和节次筛选器。
- 展示平均余量、余量充足时段数和逐楼栋时段明细。

## 数据边界

当前分析库没有完整的教室座位总量和可用教室库存，因此不能可靠计算“还剩多少座位”。本批采用 `100% - 时段利用率` 作为标准化时段余量，并在接口和页面明确展示限制说明。

该结果适合用于发现可进一步协调的楼栋和时段，但不能直接作为自动排课或教室分配指令。

## 验证结果

- 后端编译通过。
- 前端生产构建通过。
- 全量自动回归 86 项通过、0 项失败。
- 专项断言覆盖星期/节次筛选、余量公式和数据限制披露。

## 下一步

在现有数据可支持范围内生成课程可调度候选：结合目标时段余量、教学班规模、教室类型和教师历史排课分布给出建议，并逐项展示未验证约束。
