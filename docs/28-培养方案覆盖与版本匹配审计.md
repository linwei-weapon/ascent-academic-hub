# 培养方案覆盖与版本匹配审计

## 数据覆盖

- 真实培养方案：2 个专业、1 个年级版本；
- 方案元数据：2 条；
- 方案课程：567 条，去重课程 332 门；
- 可按“专业＋年级”精确匹配的学生：156 人；
- 全校学生：12,670 人；
- 精确覆盖率：约 1.23%。

未覆盖专业和年级继续返回诚实空态，不推断、不复制其他方案。

## 已识别问题

1. 原接口主要按专业查询，未来同专业多版本时会混合课程；
2. 学生进度原先纳入专业下所有年级学生；
3. 学分分母部分来自专业通用要求，而非学生适用方案版本；
4. 已修学分包含方案外课程，可能高估毕业完成度；
5. 毕业要求支撑矩阵在前后端各硬编码一份；
6. 必修/选修仍主要通过模块名称推断。

## 第一批修正

- 培养方案详情、课程目标、毕业要求和进度接口统一按“专业＋年级”读取；
- 增加 `planVersion`，格式为 `{major_id}-{grade}`；
- 返回适用年级、真实数据来源和覆盖说明；
- 学生进度只返回与方案年级精确匹配的学生；
- 应修分母使用该版本方案总学分；
- 已修学分只统计方案内已通过课程；
- 方案外已通过课程单独统计为 `outsidePlanCredits`；
- 前端展示方案版本、覆盖说明和方案外学分。
