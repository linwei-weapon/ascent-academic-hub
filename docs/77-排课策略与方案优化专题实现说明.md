# 排课策略与方案优化专题实现说明

## 1. 管理目标

面向教务处和学院排课人员，基于实际课表描述星期、时段、重点课程和教师排课行为集中度，为新学年排课准备事实证据。

## 2. 当前口径

- 排课记录：解析后的周次—星期—节次记录，不是课程门数。
- 高峰时段：排课记录最多的星期与时段，只表示当前分布集中，不证明发生资源冲突。
- 教师行为集中度：教师实际排课记录中出现最多的星期和时段占全部记录的比例，不是教师主动填报偏好。
- 体育课、思政课按课程类别和课程名称规则识别，生产系统应改用课程标签主数据。

## 3. 已实现

- 接口：`GET /api/v2/topics/schedule-strategy`，默认响应约0.07秒。
- 页面：`/admin/reports/schedule-strategy`。
- 展示教学班、课程、教师、排课记录和最集中时段。
- 展示星期—时段分布、体育与思政课程分布、教师实际排课集中时段样本。
- 所有指标均提供单位、口径、管理用途和数据边界。

## 4. 当前边界与生产要求

当前只有一个真实课表学期，因此不能称为稳定历史偏好，也不能生成新学年A/B优化结论。生产系统需要接入至少三年以上课表、新学年教学任务、班级与课程冲突关系、教师不可用时间、连续节次要求、教室容量与类型、校区移动时间和可用教室快照。

生产优化应区分硬约束和软偏好，输出候选方案的冲突数、教师偏好满足率、学生课表离散度、教室适配率和高峰削减量，由排课人员确认，不自动发布最终课表。
