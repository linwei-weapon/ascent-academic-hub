# 教学运行与师资分析 PRD 及 API 契约

## 1. 产品目标与范围

本模块帮助校级和学院管理者基于真实教学任务、课程日历、教室和教师关系回答：

- 各学期、年级和课程类别的开课分布是否合理。
- 体育、思政等重点课程的排课时段是否过度集中。
- 教室资源分析所使用的可用数量和容量是否可信。
- 每门课程由哪些教师承担，课程团队是否存在资源集中或档案缺口。
- 教师历史实际排课呈现何种时间分布。

不在范围内：排课编制、调课审批、教室维护、教师主动填报偏好、教师绩效评价。

## 2. 角色和权限

| 角色 | 能力 |
|---|---|
| 校级管理者 | 查看全校开课、时段、教室和团队汇总，可下钻课程和教师 |
| 学院管理者 | 查看授权学院的开课、课程团队及教师汇总 |
| 系部负责人 | 查看授权专业或系部范围的课程和教师汇总 |
| 普通教师 | 本模块默认不开放全校汇总；如开放，仅查看本人及授权课程 |

生产接口必须在服务端实施范围过滤；菜单权限不能替代数据权限。

## 3. 功能需求

### `COURSE-01` 单门课程开课情况

- 按学期、学院、课程类别、性质、年级和关键词筛选。
- 展示课程代码、名称、开课单位、教学班数、教师数、选课人次和班额。
- 支持进入课程团队详情。
- 数据为空时显示“该学期尚未接入真实教学任务”，不得回退为模拟数据。

### `COURSE-02` 课程时段分布

- 展示星期×时段热力图。
- 支持全部课程、体育课、思政课和标准课程标签筛选。
- 每个格子显示排课片段数、教学班数和课程数。
- 页面披露标签覆盖率、未解析课表数量和数据更新时间。

### `ROOM-01` 教室资源分析

- 展示楼宇、房间总数、上游标记可用数量、可用座位数。
- 利用率分母必须使用上游确认的可用资源口径。
- 容量无效、楼宇未映射和停用后仍被排课必须进入质量摘要。
- 本模块不提供教室数据编辑功能。

### `FAC-01` 课程团队

- 按课程和学期展示实际授课成员、角色、职称、组织和承担教学班数。
- 展示团队人数、职称结构、课程负责人覆盖和单点承担情况。
- 档案缺失与业务风险分开显示；缺失职称不得计算为低职称。
- 风险只用于资源核验，不形成教师绩效结论。

### `FAC-02` 历史排课时间分布

- 基于多个真实学期的课程日历汇总星期和时段。
- 返回样本学期数、排课片段数、课程数和稳定性。
- 标题和说明统一使用“历史实际排课分布”，不得表述为教师主动填报偏好。
- 样本不足时只显示事实分布，不输出稳定偏好结论。

## 4. 页面与交互状态

所有页面必须覆盖加载中、正常、无数据、部分数据、权限不足、接口失败六种状态。筛选条件应进入 URL 或可恢复状态；切换学期后所有卡片、表格和图表使用同一数据版本。真实、派生和模拟数据必须有明确标识，生产环境不得用模拟数据补空。

## 5. 指标定义

| 指标 | 公式 | 边界 |
|---|---|---|
| 开课课程数 | 去重 `semester_id + course_id` | 不等同教学班数 |
| 教学班数 | 有效教学任务去重数 | 取消任务不计入 |
| 教师数 | 有效教学任务教师关系去重 | 缺教师关系需披露 |
| 排课片段数 | 有效课程日历记录去重 | 调课后被替代记录不计入当前值 |
| 可用教室数 | 上游标记可用、非虚拟且容量有效的教室数 | 规则版本必须可追溯 |
| 团队单点承担 | 课程教学任务仅一名有效教师承担 | 不直接等同人才危机 |
| 偏好稳定性 | 多学期时段分布的一致性统计 | 至少三个有效学期后才允许分级 |

## 6. API 通用规范

- 基础路径：`/api/v1/analytics`；原型 `/api/v2` 仅作为语义参考。
- 认证：学校统一身份令牌；服务端解析用户及数据范围。
- 响应必须包含 `data_version`、`calculated_at`、`source_batches` 和 `quality_summary`。
- 列表采用 `page`、`page_size`，默认 20，最大 200。
- 时间和学期参数使用正式代码；无效代码返回 400，不自动替换当前学期。
- 错误结构：`code`、`message`、`trace_id`、`details`。

## 7. API 清单

| 方法与路径 | 用途 | 核心参数 |
|---|---|---|
| `GET /meta/teaching-semesters` | 有真实教学任务的学期 | 数据范围 |
| `GET /courses/offerings` | 开课列表与聚合 | 学期、学院、类别、性质、年级、关键词、分页 |
| `GET /courses/schedule-distribution` | 课程时段分布 | 学期、课程标签、学院、年级 |
| `GET /courses/{course_id}/team` | 课程团队 | 学期、课程代码 |
| `GET /teachers/{teacher_id}/schedule-distribution` | 教师历史排课分布 | 学期范围、课程类别 |
| `GET /rooms/summary` | 教室和楼宇资源基数 | 学期、校区、楼宇、类型 |
| `GET /quality/summary` | 本模块数据质量摘要 | 学期、数据域、规则代码 |

## 8. 关键响应示例

```json
{
  "data": {
    "semester_id": "2023-2024-1",
    "items": [{"course_id": "C001", "course_name": "示例课程", "lesson_count": 3, "teacher_count": 2}]
  },
  "data_version": "teaching-2023-2024-1-v4",
  "calculated_at": "2026-07-13T10:00:00+08:00",
  "source_batches": ["lesson-20260713-01", "calendar-20260713-01"],
  "quality_summary": {"warning_count": 2, "excluded_rows": 4}
}
```

## 9. 验收标准

- 任取一门课程，页面教学班、教师和选课人次与源系统对账一致。
- 体育、思政课程只依据正式标签进入专项统计。
- 任取一名教师，可从课程日历复算其星期×时段分布。
- 任取一栋楼，可复算可用教室和座位数。
- 无权学院数据返回 403 或空范围，不得通过修改参数越权。
- 质量异常能追溯到规则、批次和源记录。
- 无数据学期展示空态，无模拟回退。

## 10. 待业务确认

- 学院开课归属按课程所属单位还是教学任务承担单位。
- 合班、跨学院课程在各学院统计中的分摊规则。
- 教室“可用”的正式业务代码和有效期规则。
- 课程团队单点承担、年龄段和职称结构的风险阈值。
- 历史排课分布至少需要多少学期才可称为稳定偏好。
