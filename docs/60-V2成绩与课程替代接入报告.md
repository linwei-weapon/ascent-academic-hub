## 2. 有效成绩规则V1

适用范围：原型阶段，用于统一页面口径；不是学校最终生产制度文件。

1. 只选择已发布且未作废的记录。
2. 同一学生、同一课程存在通过记录时，优先通过记录。
3. 多条通过记录取有效得分最高者；同分时取较新学期及较后源记录。
4. 全部未通过时取最近学期记录。
5. 已通过结果获得该记录对应学分；未通过结果获得学分为0。
6. 源“是否通过”缺失时才使用数值成绩是否达到60分辅助判断。
7. 每条结果保留`effective_attempt_id`、`rule_version`、`result_basis`和计算时间。

该规则把7,423条源未通过记录归并为2,082个“学生×课程”的当前有效未通过结果，避免把同一课程多次失败重复计入学生当前挂科课程数。

## 3. 成绩字段保存

每条尝试保存：

- 学生、课程、教学班、学期；
- 课程名称和被替代课程代码/名称；
- 正常、补考、缓考或重修类型；
- 学分、必修性；
- 得分、总评、补考、缓考、加分、等级和绩点；
- 是否通过、发布状态、作废状态；
- 数据批次和源行号。

尝试ID由批次文件哈希和源行号稳定生成，同一文件重复装载不会产生重复成绩。

## 4. 课程替代处理

- 源文件41行，其中39行同时满足审核通过、流程已结束，作为生效替代事实。
- 原课程和替代课程从组合文本中解析代码、名称和学分。
- 课程替代是学生个人审批结果，不写入全校通用课程等价规则。
- 后续计算方案完成情况时，审批通过的替代课程可抵扣对应原课程，但必须保留审批证据。

## 6. 原型可启用能力

1. 统一挂科人数、挂科率、累计挂科和重修口径。
2. 查看学生逐学期成绩、首次失败、重复失败和最终通过过程。
3. 结合培养方案计算必修课程尚未完成、逾期未完成和重修候选。
4. 统计单门课程原始失败次数、当前未通过学生数和重修后通过情况。
5. 将大一挂科、连续学期失败和同类课程重复失败加入学生成长轨迹。

## 7. 仍需业务确认

- 补考、缓考、重修之间是否允许取最高成绩，或只能按指定顺序覆盖。
- 及格重修是否影响原通过结果和绩点。
- 加分成绩是独立结果、加分项还是最终成绩字段。
- 等级制课程、两级制课程是否计入GPA。
- 作废、成绩更正和发布撤回的正式关联键。

这些问题不阻塞原型使用，但生产系统上线前必须形成正式版本化规则。
