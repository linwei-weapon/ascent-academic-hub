## 2. 完成定义

整个“产品终稿”只有同时满足以下条件才算完成：

1. 菜单、路由、角色权限和默认入口一致，没有孤立或点击无响应页面。
2. 所有业务接口使用统一权限上下文，前端隐藏不能替代后端鉴权。
3. 六个预设分析模块无重复专题入口，相同指标调用同一计算口径。
4. 管理要情以变化事件为主，决策研判支持卡片化对话和情景模拟。
5. 学校个性化管理方法能够以分析方案/管理专家配置承载，不复制整套页面。
6. 校、院、班级、导师和系统管理员数据范围均通过正向和反向测试。
7. 前端构建、后端测试、端到端检查、浏览器回归和 `git diff --check` 全部通过。
8. 文档、数据库迁移、API契约、权限矩阵和验收证据同步更新。
