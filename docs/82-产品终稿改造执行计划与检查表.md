# P4 AI管理决策重构

## P4-01 管理专家与分析方案协议

每个专家至少包括：

- [ ] 专家名称、版本、适用角色和管理问题。
- [ ] 所需数据与完整性条件。
- [ ] 指标、规则、阈值和排序逻辑。
- [ ] 事件触发条件和不应触发条件。
- [ ] 输出卡片和证据路由。
- [ ] 可继续追问的意图和可调整参数。
- [ ] 推荐动作、建议责任角色和时间。
- [ ] 模拟器能力。
- [ ] 不确定性、适用边界和测试案例。
- [ ] 学校配置覆盖和版本回滚。

## P4-02 首批管理专家

- [ ] 毕业准备核查专家。
- [ ] 高影响课程保障专家。
- [ ] 课程团队连续性专家。
- [ ] 后续迁移低年级受挫和排课资源优化专家。
- [ ] 专家共享统一指标和权限上下文，不复制取数代码。

## P4-03 管理要情

- [ ] 从静态日报改为管理事件流。
- [ ] 识别新增、升级、扩大、缓解和退出关注。
- [ ] 同根因、同对象事件聚合，避免重复。
- [ ] 首屏最多显示少量高价值事件。
- [ ] 每张卡片包含变化、影响、为何现在看、首要核查动作和证据。
- [ ] “继续研判”自动带入事件、角色、范围、学期和专家。
- [ ] 无明显变化时明确显示无新增重大事项。

## P4-04 决策研判工作区

- [ ] 首页提供推荐管理问题，不以空白聊天框开始。
- [ ] 对话和结构化筛选/参数双向同步。
- [ ] 系统显示“我理解的分析范围和临时条件”。
- [ ] 结果以事件卡、证据卡、比较卡和候选决策单呈现。
- [ ] 临时会话调整不改变正式管理口径。
- [ ] 保存为正式分析方案需要授权和发布流程。
- [ ] 决策模拟作为研判能力嵌入，不再单独菜单。
- [ ] 原三类模拟场景继续可用。

## P4-05 AI权限与追溯

- [ ] 专家运行前使用统一权限上下文。
- [ ] 自然语言不能扩大组织或学生范围。
- [ ] 下钻证据再次鉴权。
- [ ] 缓存键包含范围指纹、角色、专家版本和参数版本。
- [ ] 角色切换或关系失效后旧会话失效。
