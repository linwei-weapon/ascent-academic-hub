# 基础报表 9 个统计分析报表详细功能需求说明书

## 1. 文档说明

### 1.1 编制目的

本文档用于完整说明“基础报表”模块下 9 个只读统计分析报表的功能、查询条件、标题、结果字段、统计公式、汇总、空数据和 Excel 导出要求，作为产品确认、开发实现、测试验收和生产交接的共同依据。

### 1.2 当前基线

- 文档基于截至 2026-08-23 的当前可运行代码、`basic-report-v1.5` 规则版本及已确认页面调整编制。
- 报表只读取、分析和导出教务及预警数据，不修改学生、成绩、学籍、课程、预警或人员关系数据。
- 演示环境中的具体人数仅用于回归核查，不是生产固定值。生产结果必须随源数据、当前工作身份和查询条件动态计算。
- 页面路径统一位于 `/admin/basic-reports/` 下；接口统一位于 `/api/admin/basic-reports/` 下。

### 1.3 报表目录

| 编号 | 报表名称 | 页面路径 | 结果类型 |

## 2. 公共功能要求

### 2.1 数据范围与权限

1. 页面选项、查询接口和导出接口均按当前工作身份重新校验菜单权限和数据范围，不能以菜单隐藏代替服务端鉴权。
2. 校级角色、教务处和明确授权的系统管理员可查看全校授权范围；二级学院、系主任、辅导员、班主任和导师分别按组织、专业、人员—班级或导师—学生关系限制数据。
3. 查询条件只能在当前授权范围内进一步收窄，不能扩大权限。切换工作身份后必须清空旧结果并重新加载可选条件。
4. 导出必须具备 `export.authorized`。RPT-07、RPT-08 还必须具备 `student.detail`，否则不得返回或导出学生明细。

### 2.2 查询交互与条件联动

1. 首次进入、切换报表或点击“重置”后，除 RPT-01 的隐含学期外不自动发起业务查询，结果区保留该报表的固定表头。
2. 带 `*` 的条件必须输入。必填条件不完整时，页面提示缺失条件，不发送查询请求。
3. 学院、专业、班级均来自当前身份授权范围：
   - 专业选项随学院联动；学院变化后，已选专业不属于新学院时自动清空专业。
   - 班级选项随专业联动；专业变化后，已选班级不属于新专业时自动清空班级。
   - 未选择上级条件时，可在当前身份全部授权范围内选择下级条件。
4. 查询一次返回当前条件下的全部结果，不做前端分页。表格支持列显隐、列顺序、密度和列宽等公共表格能力，但不得改变必需业务字段及计算口径。

### 2.3 成绩公共口径

除 RPT-06、RPT-07、RPT-08 的专用数据源外，成绩统计必须满足：

```text
is_published = 1
AND is_void = 0
AND is_pass IS NOT NULL
AND semester_id = 所选学年学期
```

- “首次有效结果”只在非补考、非重修记录中按源行号和尝试记录顺序取第一条结果。
- “当前有效结果”按学生—课程去重；存在有效通过记录时以通过为已解决，否则取最新未通过结果。
- 人数指标均按学生去重；同一学生多门课程挂科时，在学生人数指标中只计 1 人，在挂科门数指标中按不同课程计数。
- 百分比分母为 0 时，数值型比例显示“—”；RPT-03 男女展示字段按其专门规则显示 `-`。

### 2.4 页面与空数据公共要求

1. 9 张报表均采用紧凑布局，不重复显示报表编号页头和查询上下文条；导出入口位于查询结果标题右侧。
2. 查询前表格仅显示固定表头，表体不显示“无数据”提示。
3. 查询成功但结果为空时，保留完整表头，表体显示“当前授权范围和筛选条件下无数据”。
4. `source_unavailable` 表示源数据或快照未接入，不能解释为业务人数为 0；`detail_forbidden` 表示当前身份没有名单明细权限。
5. 空结果若状态仍为 `available`，允许按权限导出只有标题、表头和说明的 Excel；`source_unavailable`、`detail_forbidden` 状态禁止导出。

### 2.5 Excel 公共要求

1. Excel 固定包含“报表结果”“报表说明”“口径规则”3 张工作表。
2. “报表结果”第 1 行合并全部业务列，显示与页面查询结果完全相同的后端标题；后续为表头和数据。
3. “报表说明”记录报表编号、标题、状态、导出账号、当前工作身份、学年学期、年级、学院/专业/班级筛选、口径版本、数据截止时间和适用边界。
4. “口径规则”记录本报表使用的规则编号、来源类型、来源、公式和适用边界。
5. 页面查询成功后返回签名查询快照。导出必须使用相同报表、工作身份、筛选条件、数据文件版本和规则版本；任一项变化时旧快照失效，提示重新查询。
6. 文件名格式为 `报表编号_报表名称_学年学期_年级_时间戳.xlsx`。年级未选择时使用“全部年级”。
7. 导出内容与页面使用相同的字段顺序、展示文本、默认排序和汇总结果，不得额外混入未授权字段或学生。

## 3. RPT-01 年级总体挂科情况

### 3.1 简要功能说明

按年级展示本科生总人数、补考前已挂人数、补考后仍在挂人数，以及男、女分布和正式留降级人数，用于核查年级挂科规模及补考前后变化。

### 3.2 查询条件与条件说明

| 查询条件 | 必填 | 页面显示 | 说明 |
|---|---|---|---|
| 学年学期 | 系统必取 | 否 | 自动采用当前身份可用的最新学期，用户不能手工切换 |
| 年级 | 是 | 是 | 页面标签为“年级”，底层按 `entryGrade` 过滤 |

查询时必须选择年级。重置后清空年级并保留系统自动采用的最新学期。

### 3.3 标题显示规则

标题模板：`本科{年级} 级总体挂科情况`。

- 标题不显示学年学期。
- 页面与 Excel 必须使用同一标题，例如“本科2022 级总体挂科情况”。

### 3.4 查询结果列与计算公式

| 列 | 说明 | 计算与展示要求 |
|---|---|---|
| 本科生 | 固定 3 类：总人数、已挂人数、在挂人数 | “总人数（留降级）：主人数（留降级人数）”；已挂、在挂类别另起一行显示类别比例 |
| 性别 | 男、女 | 每个类别固定 2 行 |
| 人数 | 当前类别、当前性别人数及其中留降级人数 | `当前类别∩当前性别学生`；显示“人数（留降级人数）” |
| 比例 | 当前类别、当前性别人数占年级有效成绩学生数的比例 | `当前类别当前性别人数 ÷ 年级有效成绩学生总数 × 100%`；显示“分子/分母=百分比”，保留 2 位小数 |

集合与类别公式：

| 指标 | 计算公式 |
|---|---|
| 年级总人数 | 所选年级、当前权限范围内在校本科生去重人数 |
| 有效成绩学生数 | 年级总人数中在隐含截止学期至少存在 1 条有效成绩的去重人数 |
| 已挂人数 | 至少存在 1 门普通考试首次有效结果未通过的去重学生数 |
| 已挂比例 | `已挂人数 ÷ 有效成绩学生数 × 100%` |
| 在挂人数 | 至少存在 1 门当前有效结果仍未通过的去重学生数 |
| 在挂比例 | `在挂人数 ÷ 有效成绩学生数 × 100%` |
| 留降级人数 | 截至学期末最新正式事件为“留级”或“降级”，且当前责任年级等于所选年级的在校本科生去重人数；“保留学籍”不计入 |

责任年级优先从当前行政班名称中的严格年级段识别；识别失败时回退正式异动后的年级。留降级括号人数与主体入学年级人数分开计算。

### 3.5 汇总、排序与展示

- 本报表没有额外“总体情况”行，3 个统计类别本身即为年级汇总。
- 类别顺序固定为总人数、已挂人数、在挂人数；每类内部固定为男、女。
- 同一类别的“本科生”单元格在页面和 Excel 中跨男、女 2 行合并。
- 当前类别人数和留降级人数均按学生去重。



### 3.6 Excel 导出要求

- “报表结果”合并 `A1:D1` 显示标题；第 2 行为“本科生、性别、人数、比例”；第 3 行开始写入 6 行结果。

- “本科生”列按 3 个类别分别合并 2 行；冻结窗格为 `A3`。

- Excel 比例必须保留页面的“分子/分母=百分比”文本，不转换为其他分母。



## 4. RPT-02 各专业补考前后挂科率比较

### 4.1 简要功能说明

在所选学期和年级内，按专业比较补考前已挂人数、补考后仍在挂人数及通过率，并单列正式留降级人数，用于核查补考结果和专业差异。

### 4.2 查询条件与联动说明

| 查询条件 | 必填 | 说明 |
|---|---|---|
| 学年学期 | 是 | 限定普通考试首次结果与后续补考结果的同一学期 |
| 年级 | 是 | 标签为“年级”，按 `entryGrade` 过滤 |
| 学院 | 否 | 只显示当前身份授权学院；不选时统计全部授权范围 |
| 专业 | 不提供 | 报表结果本身按专业展开；页面和直接 API 均忽略专业参数 |
| 班级 | 不提供 | 页面和直接 API 均忽略班级参数 |

### 4.3 标题显示规则

模板：`{学年学期} 学期 {年级} 级[ {学院名称}] 各专业补考前后挂科率比较`。

- 学院未选择时省略学院名称。
- 标题不显示“本科”、专业或班级。
- 空结果时仍应按授权选项解析并显示所选学院名称。

### 4.4 查询结果列与计算公式

对每个专业定义：主体学生集合 `S_m`、责任年级留降级集合 `D_m`、普通考试首次不及格集合 `F_before`、该集合中后续仍未通过集合 `F_after`。

| 列 | 说明与公式 |
|---|---|
| 专业名称 | 当前学生维度中的专业名称 |
| 专业人数 | `COUNT(DISTINCT S_m)`；括号为 `COUNT(DISTINCT D_m)`，显示“主人数（留降级人数）” |
| 已挂人数 | `COUNT(DISTINCT S_m ∩ F_before)`；括号为 `COUNT(DISTINCT D_m ∩ F_before)` |
| 挂科率（补考前） | `已挂人数 ÷ 专业人数 × 100%` |
| 在挂人数 | `COUNT(DISTINCT S_m ∩ F_after)`；括号为 `COUNT(DISTINCT D_m ∩ F_after)` |
| 挂科率（补考后） | `在挂人数 ÷ 专业人数 × 100%` |
| 通过率 | `（专业人数－在挂人数）÷ 专业人数 × 100%` |

`F_after` 只能从 `F_before` 对应的同一学生—课程组合派生，因此专业行与汇总行均必须满足“在挂人数 ≤ 已挂人数”。只有重修未通过、但没有本学期普通考试首次不及格记录的课程，不进入补考前后比较集合。

### 4.5 汇总、排序与展示

1. 最后一行固定显示“总体情况(留降级)”。各项人数在当前查询范围内重新按学生去重，不能简单相加可能重复的明细记录。
2. 专业行按补考后挂科率降序、在挂人数降序、专业名称升序排列；汇总行固定在最后。
3. 百分比保留 2 位小数，专业人数为 0 时显示“—”。

### 4.6 无数据说明

当前授权范围或所选学院、年级没有专业学生时，保留 7 列表头，不显示汇总行，表体显示统一无数据文案。

### 4.7 Excel 导出要求

- 合并 `A1:G1` 显示页面标题；第 2 行为 7 列表头；第 3 行开始写入专业行，最后写入汇总行；冻结窗格为 `A3`。
- 人数括号、比例和汇总内容必须与页面一致。
- “口径规则”至少包含学生范围、有效成绩、首次结果、当前有效结果、留降级及专业补考比较规则。

## 5. RPT-03 各专业整体与男女挂科率比较

### 5.1 简要功能说明

按专业比较补考后整体挂科率及男、女生挂科率，展示专业人数、整体挂科人数和对应留降级人数，为核查专业与性别差异提供事实统计，不自动生成性别归因结论。

### 5.2 查询条件与条件说明

| 查询条件 | 必填 | 说明 |
|---|---|---|
| 学年学期 | 是 | 限定当前有效成绩和挂科状态 |
| 年级 | 是 | 标签为“年级”，按 `entryGrade` 过滤 |
| 学院 | 不提供 | 结果直接继承当前身份授权范围 |
| 专业 | 不提供 | 报表结果按专业展开 |
| 班级 | 不提供 | 不提供页面收窄 |

### 5.3 标题显示规则

模板：`{学年学期} 学期本科 {年级} 级各专业整体与男女挂科率比较`。

标题不写入学院、专业和班级。页面与 Excel 必须使用同一标题。

### 5.4 查询结果列与计算公式

| 列 | 说明与当前计算公式 |
|---|---|
| 专业 | 显示“专业名称(留降级)”；汇总行显示“总体情况(留降级)” |
| 专业人数 | 当前入学年级主体学生去重人数；括号为该专业责任年级留降级学生人数，显示“主人数（留降级人数）” |
| 整体挂科人数 | 专业主体学生中至少 1 门当前有效结果未通过的去重人数；括号为责任年级留降级学生中当前仍挂科人数 |
| 整体挂科率 | `整体挂科人数 ÷ 专业有效成绩学生数 × 100%` |
| 男生挂科率 | `男生挂科人数 ÷ 男生有效成绩学生数 × 100%`；显示“分子/分母=百分比” |
| 女生挂科率 | `女生挂科人数 ÷ 女生有效成绩学生数 × 100%`；显示“分子/分母=百分比” |

男女比例分母为当前代码中的对应性别有效成绩学生数。该性别分母为 0 时显示 `-`；非零时使用半角 `/`，百分比保留 2 位小数。未说明性别的学生进入整体人数和整体挂科率，但不进入男、女分母。

专业人数括号与整体挂科人数括号是不同集合。例如“专业人数（2）/整体挂科人数（1）”表示有 2 名责任年级留降级学生，其中 1 人当前仍挂科，不属于重复或漏数。

### 5.5 汇总、排序与展示

1. 最后一行固定显示“总体情况(留降级)”，对当前授权范围内全部主体学生和责任年级留降级学生重新去重计算。
2. 专业行按整体挂科率降序、整体挂科人数降序、专业名称升序排列；汇总行固定最后。
3. 汇总行男女比例分别使用全范围男、女有效成绩学生数作为分母。

### 5.6 无数据说明

当前范围没有专业学生及责任年级留降级学生时，保留 6 列表头，不生成汇总行。性别分母为 0 不属于整表无数据，只在对应单元格显示 `-`。

### 5.7 Excel 导出要求

- 合并 `A1:F1` 显示与页面一致的标题；第 2 行为 6 列表头；第 3 行开始写入专业行和汇总行；冻结窗格为 `A3`。
- 专业名称后缀、两个人数括号及男女“分子/分母=百分比”文本必须与页面逐行一致。
- 不导出自动性别评价或归因结论。

## 6. RPT-04A 各班级挂科门数具体情况

### 6.1 简要功能说明

按班级统计学生当前未解决课程门数分布，重点展示挂 1—2 门、3—5 门和 6 门及以上的学生规模，用于识别班级集中性学业困难。

### 6.2 查询条件与联动说明

| 查询条件 | 必填 | 说明 |
|---|---|---|
| 学年学期 | 是 | 限定当前有效课程结果 |
| 年级 | 是 | 按 `entryGrade` 过滤 |
| 学院 | 否 | 受当前权限约束；不选时统计全部授权学院 |
| 专业 | 否 | 与学院联动；不选时统计当前学院或全部授权专业 |
| 班级 | 不提供 | 结果本身按班级展开；直接 API 请求同样忽略班级参数 |

### 6.3 标题显示规则

模板：`{学年学期} 学期 {年级} 级[ {学院名称}][ {专业名称}] 各班级挂科门数具体情况`。

学院、专业未选择时依次省略；标题不显示“本科”或班级名称。空结果仍应保留已选学院、专业的显示名。

### 6.4 查询结果列与计算公式

对学生 s，定义 `U_s` 为所选学期当前有效结果仍未通过的不同课程数。

| 列 | 说明与公式 |
|---|---|
| 班级 | 当前行政班名称 |
| 总人数 | 班级内在校本科生去重人数，包括 `U_s=0` 的学生 |
| 1-2科 | `COUNT(DISTINCT student_id WHERE 1 ≤ U_s ≤ 2)` |
| 3-5科 | `COUNT(DISTINCT student_id WHERE 3 ≤ U_s ≤ 5)` |
| 5科以上 | 页面保留原表列名，实际计算为 `COUNT(DISTINCT student_id WHERE U_s ≥ 6)`，避免与“3-5科”重复 |

内部同时计算 0 门学生数，但当前结果列不展示该值。

### 6.5 汇总、排序与展示

- 最后一行显示“总体情况”，总人数和 3 个区间均在当前查询范围内重新计算。
- 汇总中的挂科学生数等于 `U_s>0` 的学生数，但当前表格不单独展示该内部指标。
- 班级行按学院、专业、班级的稳定顺序展示；汇总行固定最后。

### 6.6 无数据说明

没有授权班级学生时，保留 5 列表头，不显示“总体情况”行。某班有学生但所有学生 `U_s=0` 时，该班仍显示，总人数非 0，3 个挂科区间均为 0。

### 6.7 Excel 导出要求

- 合并 `A1:E1` 显示标题；第 2 行为 5 列表头；第 3 行开始写入班级和汇总结果；冻结窗格为 `A3`。
- Excel 列名继续显示“5科以上”，计算仍为 6 门及以上。
- 导出不得增加页面未显示的 0 门学生列。

## 7. RPT-04B 各班级成绩分布

### 7.1 简要功能说明

先在所选专业范围内按学生学分加权平均成绩排序并划分 20%/30%/30%/20% 区间，再按班级统计各区间人数和占比，用于比较同一专业内不同班级的成绩结构。

### 7.2 查询条件与联动说明

| 查询条件 | 必填 | 说明 |
|---|---|---|
| 学年学期 | 是 | 限定参与平均分计算的有效成绩 |
| 年级 | 是 | 按 `entryGrade` 过滤 |
| 学院 | 是 | 只能选择当前身份授权学院 |
| 专业 | 是 | 与学院联动；必须选择具体专业后查询 |
| 班级 | 否 | 与专业联动；不选时展示该专业全部班级，选择后只展示目标班级 |

学院或专业变化后，下级无效选项必须自动清空。4 个必填条件任一缺失时不得查询。

### 7.3 标题显示规则

- 未选择班级：`{学年学期} 学期 {年级} 级 {学院名称} {专业名称} 各班级成绩分布`。
- 选择班级：`{学年学期} 学期 {年级} 级 {学院名称} {专业名称} {班级名称} 成绩分布`。
- 空结果仍应按授权维表解析学院、专业名称，不能退化为代码值。

### 7.4 查询结果列与计算公式

先对每名有有效成绩的学生计算：

```text
学分加权平均成绩 = SUM（课程当前有效成绩 × 课程学分）÷ SUM（课程学分）
```

若该生所有课程学分之和为 0，则退化为课程成绩算术平均。之后在“同一学院 + 同一专业”的全部有成绩学生范围内，按平均成绩降序、学号升序形成稳定序号 `i`，设专业有成绩人数为 `N`：

- `i/N ≤ 20%`：专业前 20%；
- `20% < i/N ≤ 50%`：专业前 20%—50%；
- `50% < i/N ≤ 80%`：专业前 50%—80%；
- `i/N > 80%`：专业后 20%。

| 列 | 说明与公式 |
|---|---|
| 班级 | 当前行政班名称 |
| 总人数 | 当前页面实际展示该班“有成绩排名人数”，不是行政班全部在校人数 |
| 专业前20% | 当前班位于专业前 20% 的人数及其占班级有成绩人数比例，显示“人数（百分比）” |
| 专业前20-50% | 当前班位于第二分桶的人数及比例 |
| 专业前50-80% | 当前班位于第三分桶的人数及比例 |
| 专业后20% | 当前班位于最后分桶的人数及比例 |

分桶比例分母均为该班有成绩排名人数。无有效成绩学生不参与专业排名，也不进入当前“总人数”展示值；内部保留无成绩人数用于核查。

### 7.5 汇总、排序与展示

- 本报表不显示总体汇总行。
- 排名必须先在专业总体范围内完成，再回填班级，禁止在各班内部独立切分 20%/30%/30%/20%。
- 同分不共享名次；学号升序作为稳定次序，因此分桶边界由序号位置决定。
- 每个班 4 个区间人数之和必须等于该班有成绩排名人数。

### 7.6 无数据说明

- 所选专业没有班级学生时显示 6 列空表头和统一无数据文案。
- 班级有学生但无人有有效成绩时，该班可显示“总人数 0”，各区间显示“0（—）”；不能将无成绩学生分配到任一成绩区间。

### 7.7 Excel 导出要求

- 合并 `A1:F1` 显示标题；第 2 行为 6 列表头；第 3 行开始写入班级结果；冻结窗格为 `A3`。
- Excel 只导出页面 6 列，不导出学生平均分、学生排名或无成绩学生明细。
- 各区间继续使用“人数（百分比）”文本，页面与 Excel 必须一致。

## 8. RPT-05 补考前后课程通过情况对比

### 8.1 简要功能说明

按课程和专业对比普通考试首次结果与补考后结果，展示专业内挂科人数、跨专业课程挂科总人数及补考通过人数，用于核查课程层面的补考效果。

### 8.2 查询条件与联动说明

| 查询条件 | 必填 | 说明 |
|---|---|---|
| 学年学期 | 是 | 所有首次、补考和当前结果均限定在该学期 |
| 年级 | 否 | 不选时查询全部授权年级 |
| 学院 | 否 | 受当前身份权限约束 |
| 专业 | 否 | 与学院联动；可进一步收窄专业 |
| 班级 | 不提供 | 页面和直接 API 均忽略班级参数 |

### 8.3 标题显示规则

模板：`{学年学期} 学期[ {年级} 级][ {学院名称}][ {专业名称}] 补考前后课程通过情况对比`。

年级、学院、专业未选择时依次省略，标题不显示班级。

### 8.4 查询结果列与计算公式

结果采用 2 级表头，共 12 列：

| 列/分组 | 说明与公式 |
|---|---|
| 科目 | 课程名称，下一行显示 `[学分 学分]` |
| 专业 | 课程记录对应学生的当前专业 |
| 专业人数 | 当前查询条件下该专业在校本科生去重人数 |
| 补考前—挂科人数 | 该课程、该专业中普通考试首次有效结果未通过的学生数 |
| 补考前—专业挂科率 | `该课程该专业补考前挂科人数 ÷ 该课程该专业首次结果明确人数 × 100%` |
| 补考前—挂科总人数 | 该课程在当前授权查询范围内跨专业补考前挂科学生去重总数 |
| 补考前—总挂科率 | `该课程补考前挂科总人数 ÷ 该课程首次结果明确学生总数 × 100%` |
| 补考后—挂科人数 | 首次不及格学生中，同一课程后续有效结果仍未通过的人数 |
| 补考后—专业挂科率 | `该课程该专业补考后挂科人数 ÷ 该课程该专业首次结果明确人数 × 100%` |
| 补考后—挂科总人数 | 该课程跨专业补考后仍未通过学生去重总数 |
| 补考后—总挂科率 | `该课程补考后挂科总人数 ÷ 该课程首次结果明确学生总数 × 100%` |
| 补考通过人数 | 该课程、该专业中普通考试首次不及格且存在明确补考通过记录的去重学生数 |

“专业人数”是专业总体学生数；“专业挂科率”的实际分母是该课程、该专业首次结果明确人数，两者不是同一字段，验收时不得用“挂科人数 ÷ 专业人数”替代当前课程率公式。

### 8.5 汇总、合并与排序

- 本报表不显示独立总体行，但每门课程包含跨专业的“挂科总人数”和“总挂科率”课程级汇总。
- 同一课程的科目、补考前挂科总人数/总挂科率、补考后挂科总人数/总挂科率在多个专业行间合并显示。
- 按补考后课程挂科总人数降序、补考前课程挂科总人数降序、课程代码、学院、专业排序。
- 同一学生同一课程在课程总人数中只计 1 人。

### 8.6 无数据说明

### 8.7 Excel 导出要求

- 合并 `A1:L1` 显示标题；第 2—3 行为两级表头；第 4 行开始写入数据；冻结窗格为 `A4`。
- 第 2 行分为“补考前数据”和“补考后数据”两个表头组；科目、专业、专业人数、补考通过人数跨两行合并。

- 一名学生一行，不分页；按挂科门数降序、挂科学分降序、学号升序。
- 同一查询条件下，RPT-08 与 RPT-07 的学生集合、8 个业务字段、排序、课程证据和权限状态必须一致。

### 11.6 无数据与权限状态

`available` 空结果、`source_unavailable` 和 `detail_forbidden` 的判定、页面提示及导出控制与 RPT-07 完全一致。RPT-08 不得在没有独立正式名单源时伪造校级警示人数。

### 11.7 Excel 导出要求

- 合并 `A1:H1` 显示以“校级学业警示学生名单”结尾的标题；第 2 行为 8 列表头；第 3 行开始写入学生；冻结窗格为 `A3`。
- “报表说明”和“口径规则”结构与 RPT-07 相同，报表编号必须为 RPT-08。
- RPT-07 与 RPT-08 的查询快照分别绑定各自编号，不能交叉用于导出。

## 12. 跨报表验收要求

### 12.1 结果一致性

1. 页面、查询接口与 Excel 的标题、字段、排序、汇总和展示文本必须一致。
2. 人数均按相应集合中的学生去重；课程数按学生—课程去重；课程级总人数不得重复累计同一学生。
3. 留降级人数只读取截至所选学期末已生效的正式“留级/降级”事件，“保留学籍”不计入。
4. RPT-02 的在挂集合必须是已挂集合的子集；RPT-07、RPT-08 同条件业务结果必须一致。
5. RPT-04B 的 4 个成绩区间必须覆盖且仅覆盖班级有成绩排名学生。

### 12.2 权限验收

至少覆盖以下身份：校级角色、二级学院、两个不同辅导员或班主任、两个不同导师、系统管理员。每类身份均须验证页面、直接接口、导出和身份切换后的数据隔离。

### 12.3 空数据验收

每张报表至少验证：查询前空表、查询后业务空结果、分母为 0、无权限、数据源未接入（适用时）和空 Excel。任何空状态都必须保留固定表头，不得用演示数据补齐正式结果。

### 12.4 当前待确认事项

1. RPT-03 男、女生挂科率当前分别以对应性别有效成绩学生数为分母。曾提出改用对应专业总人数，但已明确暂不修改；学校确认前保持当前实现。
2. RPT-03 专业人数括号统计全部责任年级留降级学生，整体挂科人数括号统计其中当前仍挂科学生，因此两者可能不同。是否统一显示全部留降级人数，仍需业务确认。
3. RPT-04A 页面列名“5科以上”与实际“6科及以上”计算存在历史命名差异；正式上线前建议确认是否调整列名。
4. RPT-08 当前与 RPT-07 共用 R2/R2W 活动预警名单；若学校提供独立校级学业警示批次，必须另行定义名单来源、字段、状态和历史版本要求。
