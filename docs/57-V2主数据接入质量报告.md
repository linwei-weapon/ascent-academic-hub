- 课程文件的“管理院系”是名称，组织机构使用部门代码；已按组织全称精确转换，2,233 门课程均完成组织映射。

- 房间资源口径“可用、非虚拟、座位数大于 0”得到 225 间，作为原型默认可用教室分母。
- 学期、组织、课程、楼宇、房间和节次均以学校源代码作为业务主键，不再使用 ETL 顺序生成的代码。

## 5. 原型使用决定

1. 课程、组织、学期和节次可直接替换原型中对应的派生维度。
2. 楼宇、房间先供教室资源和利用率模块使用；管理员覆盖值继续保留。
3. 未匹配楼宇不阻塞后续学生、方案和教学任务接入。
4. 页面统计需显示当前可用房间口径，不能把全部 539 个房间作为可排课分母。
5. 当前批次只有房间可用状态快照，不用于反推历史学期房间可用性。
