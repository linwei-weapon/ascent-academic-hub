# 规则审批影响分析与候选导出

## 目标

让规则审核人不仅看到影响总人数，还能查看参数变化和受影响学生在学院、专业、年级上的分布，并能够导出候选名单进行线下复核。

## 影响分析接口

`GET /api/admin/settings/rule-changes/{change_id}/analysis`

返回：

- 变更前后参数及是否发生变化；
- 规则启用状态变化；
- 学院分布及各学院新增、保留、退出人数；
- 专业分布及新增、保留、退出人数；
- 年级分布及新增、保留、退出人数；
- 候选动作分布；
- 预警等级分布。

接口要求 `audit` 权限。

## 候选导出

`GET /api/admin/settings/rule-changes/{change_id}/candidates.csv`

导出字段：学号、姓名、学院、专业、班级、年级、变化类型、预警等级和候选命中说明。

CSV 使用 UTF-8 BOM，便于 Excel 直接打开中文内容。导出同样要求 `audit` 权限。

## 页面

规则变更单新增：

- “影响分析”入口；
- 参数变更表；
- 学院、专业、年级分布页签；
- 候选明细中的“导出候选 CSV”。
