# 2-样式规范

> 新增规范正文，2026-09-14。采用当前高校平台 Style A“靛蓝清爽”，参考 QuizTestDemo 的规范组织方式，不移植其黑白灰品牌风格。以下数值来自现有代码；没有执行全站视觉改版。

## 一、样式来源与加载顺序

入口 main.ts 加载 Tailwind 与全局 SCSS，并调用 applyStyleA。全局 SCSS 顺序为 reset、app、Element Plus 适配、style-a。theme.ts 通过 documentElement 内联变量设置 Element Plus 色阶，style-a.scss 提供页面的 sa-* 变量和公共类。

当前主色在 theme.ts 与 style-a.scss 均有声明，需要保持一致；尚不能宣称已合并成单一 token 文件。新增页面使用现有变量，不能在 scoped 中建立新的 :root 或私自覆盖 `--el-color-primary`。

源码依据：[theme.ts](../../code/frontend/src/utils/theme.ts)、[style-a.scss](../../code/frontend/src/assets/styles/core/style-a.scss)、[样式入口](../../code/frontend/src/assets/styles/index.scss)。

## 二、色彩系统

| 变量或语义 | 当前值 | 使用位置 |
| --- | --- | --- |
| `--sa-primary` / Element Plus primary | `#4F46E5` | 主按钮、激活导航、主强调 |
| `--sa-teal` / success | `#0D9488` | 正向或成功状态 |
| `--sa-amber` / warning | `#D97706` | 关注、待核查等提醒 |
| `--sa-danger` / danger | `#E11D48` | 风险、失败或危险操作 |
| `--sa-text` | `#1E293B` | 标题和主要正文 |
| `--sa-muted` | `#64748B` | 次要信息 |
| `--sa-faint` | `#94A3B8` | 低强调辅助信息 |
| `--sa-border` | `#EAEDF2` | 卡片和表格描边 |
| `--sa-border-2` | `#E2E8F0` | 较强分隔 |
| `--sa-bg` | `#F8FAFC` | 页面背景 |
| `--sa-row-hover` | `#F1F5F9` | 表格行悬浮 |
| `--sa-track` | `#EEF2FF` | 进度与弱强调底色 |

主色表达操作与选中，状态色表达业务语义，不用整片风险红色覆盖普通数据区域。相同状态在图表、标签和名单中保持一致；颜色必须配合名称或图标，不能只凭红绿区分。

```css
.module-note {
  color: var(--sa-muted);
  border-top: 1px solid var(--sa-border);
}
```

## 三、字体与排版

正文、标题和控件统一使用系统字体栈 `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Microsoft YaHei', sans-serif`，通过 `--sa-font-body` 配置，标题 `--sa-font-head` 和 Element Plus 字体变量引用同一配置；图表继承正文的字体配置。

| 公共类/区域 | 当前尺寸 | 使用方式 |
| --- | --- | --- |
| `.sa-page-title` | 20px / 700 | 页面主标题，避免各页自行放大 |
| `.sa-page-sub` | 13px，行高 1.6 | 页面简短说明 |
| `.sa-card-title` | 15px / 700 | 卡片标题 |
| `.sa-card-title .extra` | 12px / 400 | 标题旁补充信息 |
| 表格表头 | 12.5px / 600 | Element Plus 表格公共适配 |
| `.tnum` 与表格数字 | tabular-nums | 对齐统计数字 |

指标单位与数字分开表达，表头写清人数、人次、门数、学分和百分比。无数据、无法计算和真实为零不能显示成同一种值。不要通过裁切隐藏区分口径所必需的文字。

## 四、卡片、间距与页面布局

标准 `.sa-card` 为白底、1px 描边、14px 圆角、16px 18px 内边距。Element Plus 卡片使用相同描边和圆角，默认取消阴影。同一 el-row 中的卡片填满列高，避免无意义的高低不齐。

KPI 使用 `.sa-kpi-row`：列最小宽度 160px、自动适应可用空间、间距 12px、下边距 16px。顶栏当前高 52px、左右内边距 24px；菜单叶项高 42px、圆角 8px。

局部 padding、margin、gap 按实际布局写明确尺寸并优先复用现有公共类；跨页共用的尺寸先在公共样式统一，不为每个页面创建独立 scale。不要把 QuizTestDemo 前台 1200/1280px 画布规则直接套到本管理端。

页面按“标题与上下文 → 查询条件 → 核心指标 → 分析图表或名单 → 证据入口”组织。学生明细优先使用抽屉或弹窗保留查询现场；独立 AI 查证窗口沿用当前产品交互。

## 五、表格与分页

统一使用 AppTable 声明列字段、名称、宽度、对齐、固定位置、可见性和插槽。标识列和必要操作列不能因列偏好而失去识别与操作能力。长名单和宽表在所属区域滚动，主要操作保持可到达。

表格公共样式使用浅色表头、细边框、行悬浮及等宽数字。列配置按用户与页面保存，业务列变更时核对配置版本。不要在同一页同时出现两套控制同一结果的分页。

AppTable 配合 AppPagination 展示分页；完整集合由页面通过 useTablePagination 切片，服务端列表直接传入当前页数据和总数，不能再次切片或以当前页行数作为总数。页长沿用模块约定，默认 20 条，可选 10/20/50/100。

## 六、查询、表单和按钮

查询标签说明业务含义，必选项明确提示。查询和重置有固定位置；当前结果只随已应用条件变化。提交中显示 loading，避免重复提交；失败后保留可继续修改的输入。

页面及详情弹窗中的查询、搜索、筛选栏统一显式使用 `size="small"`：包括输入框、下拉框及同一区域的查询、重置、刷新等按钮，高度统一为 32px。宽度、筛选逻辑和已有布局沿用各页面设定；项目全局默认尺寸仍为 default，登录、编辑表单和 AI 问答输入区按原尺寸使用。

每个操作区域突出主要动作，次要动作使用较弱样式。危险或不可逆操作使用语义明确的名称及确认信息，普通查看和筛选不增加无必要的确认。

按钮直接使用全局注册的 `el-button`，不增加包装组件。尺寸参照 QuizTestDemo 的四档设定，统一维护在 [el-ui.scss](../../code/frontend/src/assets/styles/core/el-ui.scss)；颜色、圆角和交互沿用当前主题与 Element Plus。

并排的独立按钮间距统一为 **8px**，由 `--sa-button-gap` 维护。普通相邻按钮使用全局外边距；已有 Flex / Grid 操作区域添加 `sa-button-row`，使用容器 `gap: var(--sa-button-gap)` 并清除直接子按钮的左外边距，避免外边距与 gap 叠加。页头、卡片操作、查询/重置、表格操作列和弹窗底部遵循同一规则；密度切换等连续分段控件保留组合边框。

| 尺寸 | 使用方式 | 高度 | 字号 | 左右内边距 | 最小宽度 |
| --- | --- | --- | --- | --- | --- |
| 大号 Large | `size="large"` | 48px | 16px | 22px | 90px |
| 中号 Medium | 不传 size，或 `size="default"` | 40px | 14px | 18px | 90px |
| 小号 Small | `size="small"` | 32px | 13px | 14px | 按内容自适应 |
| 迷你 Mini | `class="el-button--mini"` | 28px | 12px | 10px | 按内容自适应 |

```vue
<el-button type="primary" size="large">提交</el-button>
<el-button type="primary">查询</el-button>
<el-button size="small">导出</el-button>
<el-button class="el-button--mini">展开</el-button>
```

Element Plus 原生 size 只支持 `large / default / small`，不要传 `size="medium"` 或 `size="mini"`。按钮未显式指定 size 时仍遵循 Element Plus 的表单/全局尺寸继承；没有继承值时使用中号。迷你类优先于继承或显式传入的尺寸。

`text` 按钮保留对应高度和字号，左右内边距为 12px，不设最小宽度；`link` 按钮使用对应字号，高度自适应、内边距为上下 4px / 左右 0，不设最小宽度。`circle` 按钮宽高等于对应档位高度、内边距为 0；`round` 沿用圆角外形和对应档位内边距。加载、禁用、图标和普通按钮使用相同尺寸。

搜索输入框 `el-input` 与下拉筛选框 `el-select` 共用按钮高度变量，按相同 size 对齐：

| 尺寸 | 使用方式 | 输入框 / 下拉框 / 按钮高度 |
| --- | --- | --- |
| 大号 | `size="large"` | 48px |
| 默认 | 不传 size，或 `size="default"` | 40px |
| 小号 | `size="small"` | 32px |

输入框和下拉框的字号、宽度、内边距沿用原有设定；多选下拉框使用最小高度，标签换行时自然撑高。未传 size 时仍遵循表单和全局尺寸继承。文本域不套用单行高度，搜索控件不增加 mini 档。分页中的页长选择器和跳转输入框继续跟随分页按钮高度（桌面 32px、窄屏 28px）。已有控件随全局规则生效；页面显式设置的局部尺寸仍需按具体页面核对。

校验信息放在对应字段或操作区域，公共网络错误避免页面与请求层重复弹出。不要把数据库表名、内部规则 ID 或异常堆栈直接作为产品提示。

## 七、图表与指标

复用 EChart、KpiCard、KpiLabel 等现有组件。图表标题和 Tooltip 明确时间、对象、单位与统计口径；系列颜色稳定，同一指标跨页保持可辨识。

趋势线不能用 0 替代缺失学期。排名和对比注明样本范围，图表点击下钻与标题所述范围一致。饼图比例、名单总数和指标卡遵循同一后端结果，不能在页面临时算出另一种口径。

## 八、状态、动效与可访问性

加载、刷新、无结果、源数据不足、无权限、错误分别呈现。错误提供合适的重试，空结果解释筛选范围，源数据不足说明缺少什么证据；不要将它们全部替换为“暂无数据”。

现有卡片进入动画为 0.5s、10px 轻微上浮；系统启用减少动态效果时关闭动画。新动效遵循同一限制，避免指标持续跳动或干扰表格阅读。

保留键盘焦点、可读标签、图标文本和表单可操作顺序。窄窗口下保证查询、主要操作、弹窗关闭和表格滚动可用；本次未做浏览器尺寸回归，不承诺所有历史页面已满足。

## 九、样式修改验收

修改公共样式时至少核对总览、表格、抽屉、表单和 AI 对话的代表页面。检查标题层级、边框、间距、数字单位、空状态、长文本和窄窗口。样式统一不能改变分页、筛选、指标公式或权限。

本文件将当前实际样式归纳为可执行规范，没有重写原样式文件。后续若统一 theme.ts 与 SCSS 的重复变量，应作为独立代码改动核对全部消费者。
