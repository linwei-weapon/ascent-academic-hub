## 0. 通用约定（所有页面共用，不再每页重复）

### 0.1 接口规范
- 前缀 `/api/admin`，REST 风格，查询类一律 `GET`。
- 鉴权：`Authorization: Bearer <JWT>`；未登录 401 → 跳 `/login`。
- 统一响应包络：`{ "code": 0, "msg": "ok", "data": <payload> }`（code≠0 为业务错误）。
- 通用维度过滤 query 参数（按需）：`college` / `major` / `grade` / `class` / `semester`。后端再叠加**角色数据权限**过滤（见 0.7）。
- 分页：入参 `page`(1起) / `pageSize`；返回 `{ list, total, page, pageSize }`。
- 当前学期默认取 `2025-2026-2`（settings 学期配置），可被 `semester` 覆盖。

### 0.2 真实组织维度（替换原型虚构 9 院）
- 原型把学院写死为 9 个虚构编码（`PE/GE/CE/ME/GP/SC/BA/FL/HS`）+ 虚构专业 → **全部替换为真实 14 学院 / 29 专业**（见 `数据字典.md` 真实组织维度）。
- 学院/专业 `id`：ETL 阶段以**成绩表"管理部门/专业"为主键**统一编码，选课表院系做映射对齐（口径差异以成绩表为准）。
- ⚠️ 开发期勿沿用原型 `collegeMap`/`allMajors` 硬编码字典，统一从维表接口取。

### 0.3 口径复用（多页一致，定义一次）
| 指标 | 口径公式 | 依赖真实字段 |
|---|---|---|
| 挂科率 | 未通过人次 ÷ 总修读人次 ×100% | 成绩.是否通过 |
| 平均分 | AVG(得分)，兼容数字制+等级制 | 成绩.得分 / 等级 |
| GPA | AVG(绩点)（绩点已预算好） | 成绩.绩点 |
| 优秀率 | 得分≥90 占比 | 成绩.得分 |
| 重修率 | 重修人次 ÷ 总数 | 成绩.是否重修 |
| 学分完成 | 已修学分 ÷ 培养方案要求 ×100% | 成绩.学分 ∩ 培养方案docx（仅2专业） |
| 在籍学生数 | COUNT(DISTINCT 学号) | 成绩.学号 |
| 平均班额 | AVG(已选学生数) | 教学任务.已选学生数 |

### 0.4 数据源支持度图例（承接血缘表）
🟢 真实直接支持 · 🟡 真实可算/需加工 · 🔴 真实缺失需模拟/降级

### 0.5 缺口/模拟总策略（✅已拍板，详见血缘表）
- **预警** = 规则算真预警（settings 6 规则）+ 仅模拟处理状态（待处理/已约谈/已解决）。
- **认证/课程目标/毕业要求** = 安全工程、海洋油气 **2 专业模拟**（基于真实计划课程+成绩）；其余 27 专业**降级空态**。
- **模拟数据不加"演示数据"标识**，须仿真实分布、避免穿帮。

### 0.6 隐藏页（移出演示动线）
- `/admin/school`（学校管理）、`/admin/sync`（数据同步）、`/admin/sync-detail`（同步详情）：**菜单 + 路由移除，组件代码保留**。本规格书不再展开。

### 0.7 新增页 · 登录与 RBAC（替换原型写死的 10 角色硬映射）
- **`/login`**：账号 + 密码 → 返回 JWT + 用户信息 + 该用户**可见菜单/页面/数据范围**。
- 登录后菜单由后端 RBAC 下发（不再前端写死 `ROLE_ROUTES`）。
- 角色数据权限矩阵（10 角色 × 数据范围 × 可访问页面）来自 settings 角色表，后端据此过滤每个接口返回的数据行（如院长只见本院）。
- **API**：
  - `POST /api/auth/login` body `{username,password}` → `{token, user:{id,name,roleId,roleName}, menus:[...], dataScope:{type:'all'|'college'|'major'|'grade', ids:[...]}}`
  - `GET /api/auth/me` → 同上 user/menus/dataScope（刷新用）。
  - `POST /api/auth/logout`。

## 1. 数据大屏组（5 级下钻：大屏→学院→专业→课程→学生）

> 该组 5 页原型**已走真接口**（mock 在 vite.config.ts），API 路径与响应形状已定型，阶段3 按此契约用真实数据实现即可。下钻链路：大屏行点击→学院→专业→课程；任意层→学生。

### 1.1 数据大屏 `dashboard/index.vue` · `/admin/dashboard`
- **业务含义**：全校学业数据总览，校级决策入口。
- **主要角色**：校领导、教务处处长、质量办（全校范围）。
- **数据来源/支持度**：🟢 成绩表聚合（学号/绩点/是否通过/得分/管理部门）。KPI 中"毕业率/学位授予率"🔴（2022级未毕业，模拟）、"当前预警"🟡（预警ETL算）。
- **KPI**（`kpi[]`）：在籍学生 / 开课数 / 专任教师 / 毕业率🔴 / 学位授予率🔴 / 当前预警🟡。每卡含 `label/value/formula/trend/up`。
- **可视化**：
  - 学院横向对比表：学院/人数/平均分/挂科率/预警率/学分完成（进度条）。行点击→`/admin/college/{id}`。
  - GPA 分布（5 档进度条），下拉可切学院（`gpaCollege`）。
  - 挂科集中课程 TOP8 表：课程/开课学院/挂科率/平均分/优秀率。行点击→`/admin/course/{id}`。
- **API 契约**：`GET /api/admin/dashboard`
  ```json
  { "kpi":[{"label","value","formula","trend","up"}],
    "colleges":[{"id","name","students","avgScore","failRate","alertRate","creditDone"}],
    "gpaDist":[{"range","label","percent","count"}],
    "failCourses":[{"id","name","college","failCount","totalCount","failRate","avgScore","excellentRate"}] }
  ```
- **缺口处理**：毕业率/学位授予率模拟（基于在籍人数+合理通过分布）；学分完成仅 2 专业真实、其余近似或留空。

### 1.2 学院详情 `dashboard/Detail.vue` · `/admin/college/:id`
- **业务含义**：单学院下钻，看各专业/年级/挂科课程。
- **主要角色**：院长、教学秘书（限本院）、校领导/教务处（全校）。
- **数据来源/支持度**：🟢 成绩表按 `管理部门=该学院` 聚合。
- **KPI**：动态 `kpi[]`（人数/院 GPA/挂科率/预警等）。
- **可视化**：专业表（专业/人数/GPA/挂科率/预警/趋势，行点击→`/admin/major/{id}`）；年级对比卡（学分完成进度+GPA·挂科率）；本院挂科课程表（限 6 行）。
- **API 契约**：`GET /api/admin/college/{id}`
  ```json
  { "name","kpi":[{"label","value","formula"}],
    "majors":[{"id","name","students","gpa","failRate","alertCount","trend"}],
    "gradeCompare":[{"grade","creditDone","gpaAvg","failRate"}],
    "failCourses":[{"id","name","failCount","totalCount","failRate","avgScore","credits"}] }
  ```
- **缺口**：alertCount 来自预警ETL；creditDone 仅 2 专业真实。

### 1.3 专业详情 `dashboard/MajorDetail.vue` · `/admin/major/:id`
- **业务含义**：单专业下钻，按年级展开详情 + 毕业去向。
- **主要角色**：系主任、院长、教研科。
- **数据来源/支持度**：🟢 成绩按 `专业` 聚合；毕业去向分布🔴（无去向数据→模拟）。
- **可视化**：各年级详情（学生数/GPA/挂科率/预警/学分完成 + 嵌套挂科课程表）；毕业去向分布（key-value）。
- **API 契约**：`GET /api/admin/major/{id}`
  ```json
  { "name","college","kpi":[{"label","value","formula"}],
    "gradeDetail":[{"grade","students","gpaAvg","failRate","alertCount","creditDone",
                    "courses":[{"name","failCount","totalCount","failRate"}]}],
    "goalDistribution":{"<去向>":"<数量>"} }
  ```
- **缺口**：goalDistribution 模拟（升学/就业/出国等合理比例）；creditDone 仅 2 专业真实，其余降级。

### 1.4 课程详情 `dashboard/CourseDetail.vue` · `/admin/course/:id`
- **业务含义**：单课程成绩分布 / 历年趋势 / 各班级对比。
- **主要角色**：系主任、教研科、任课教师视角。
- **数据来源/支持度**：🟢 成绩按 `课程代码` 聚合 + 教学任务补课程元数据（学分/类别/学院）。
- **可视化**：成绩分布（区间进度条，<60 红）；历年趋势表（学期/平均分/挂科率/修读人次）；各班级详情（班级/人数/平均分/挂科率/任课教师）。
- **API 契约**：`GET /api/admin/course/{id}`
  ```json
  { "name","credits","type","college",
    "kpi":[{"label","value","formula","detail"}],
    "scoreDistribution":[{"range","label","count","pct"}],
    "history":[{"semester","avgScore","failRate","totalStudents"}],
    "classDetail":[{"className","students","avgScore","failRate","teacher"}] }
  ```
- **缺口**：课程名/学分/类别从成绩+教学任务补（课程信息表残缺）；teacher 解析 `姓名(工号)`。

### 1.5 学生详情 `student/Detail.vue` · `/admin/student/:id`
- **业务含义**：单学生学业画像（只读，不干预业务）。
- **主要角色**：辅导员、教学秘书、系主任（限分管范围）。
- **数据来源/支持度**：🟢 成绩按 `学号` 取全明细 + 绩点趋势 + 预警历史🟡。
- **可视化**：信息条（学号/学院/专业班级/入学/预计毕业）；4 KPI（GPA/学分完成/预警状态/毕业预判）；GPA 趋势柱；预警历史时间线；成绩明细表（学期/课程代码/课程名/成绩/绩点/通过/修读类别/考试情况）。
- **API 契约**：`GET /api/admin/student/{id}`

## 2. 预警查看 `alert/index.vue` · `/admin/alert`

- **业务含义**：学业预警监控中心。**本平台预警全部由 ETL 按规则从真实成绩算出**（原型为 mock）。
- **主要角色**：辅导员（分管班级）、教学秘书、院长、教务处。
- **数据来源/支持度**：🟡 预警记录 = ETL 按 settings 6 规则算（学生/类型/等级/触发值**真实**）；🔴 处理状态（待处理/已约谈/已解决）**模拟**。
- **预警类型**（6）：挂科累积 / GPA下降 / 学分缺口 / 单科挂科 / 出勤异常🔴 / 选课异常。**预警等级**：严重/警告/提醒。
- **KPI**：严重 / 警告 / 提醒 / 已解决 / 解决率（均带环比 trend）。
- **可视化**：月度预警趋势（柱，按月 count）；按学院预警分布（分级堆叠柱 critical/warning/info）；重点关注卡（严重+未处理 TOP4）。
- **交互**：KPI 卡点击 = 等级筛选切换；学院/类型/等级/状态多筛选；姓名/详情→**学生抽屉**；列表分页 15/页；导出按钮；"配置规则"→`/admin/settings`。
- **学生抽屉内容**：头部(学号·学院·专业·班级) + 3 迷你KPI(当前GPA/挂科门数/学分缺口) + 学分完成进度 + GPA趋势柱 + 预警历史 + 挂科课程明细(passed=false) + 近期全部成绩。
- **API 契约**：
  - `GET /api/admin/alerts`（含筛选 query：college/type/level/status/page）
    ```json
    { "summary":{"critical","warning","info","resolved","resolvedRate"},
      "rules":[{"id","name","level","triggerType","params"}],
      "list":[{"name","sid","college","class","level","type","detail","status","time"}],
      "monthlyTrend":[{"month","count"}],
      "collegeDist":[{"name","critical","warning","info","total"}] }
    ```
  - `GET /api/admin/alerts/student/{sid}`（抽屉）→ `{gpaHistory[], creditDone, creditRequired, creditGap, alerts[], failCourses[], recentScores[]}`
  - `GET /api/admin/alerts/export`（导出当前筛选，见 §9 导出策略）
- **缺口处理**：`status` 字段模拟流转；`detail`（触发数据链）由规则引擎生成真实文本（如"近2学期GPA 2.8→2.4"）；出勤异常类无数据→该类预警**砍掉或留空**。

## 4. 培养质量分析（3 页 · 工程教育认证）

> ⚠️ 强缺口区：课程目标达成度 / 毕业要求支撑矩阵真实数据没有 → **仅安全工程、海洋油气 2 专业模拟**，其余 27 专业降级。

### 4.1 培养质量 `curriculum/index.vue` · `/admin/curriculum`
- **角色**：教研科、质量办、系主任、院长。
- **支持度**：🟡 培养方案 docx（2 专业）解析为计划课程 + 修读要求；执行分析 = 成绩 ∩ 计划课程。
