# 生产部署、容量与验收方案

## 1. 目标架构

生产系统建议分为数据接入、数据处理、分析存储、查询服务、前端应用和可观测性六层。业务源系统只向接入层提供数据；分析服务不得反向修改教务、人事或空间主数据。原型 SQLite、单机 ETL 和本地账号体系不得直接用于生产。

## 2. 环境与发布

至少设置开发、测试、预生产和生产四套隔离环境。配置、密钥和数据库凭证由环境注入并进入密钥管理；生产发布应经过构建、单元测试、契约测试、数据库迁移检查、安全扫描、预生产验收和审批。数据库变更采用向前兼容迁移，失败时优先回滚应用版本，禁止直接重置生产数据。

## 3. 容量测算方法

学校尚未确认生产规模前不写死容量承诺。实施团队应按下列变量测算：

| 变量 | 含义 |
|---|---|
| `S` | 在校及历史学生数 |
| `G` | 年均成绩尝试数 |
| `L` | 年均教学班数 |
| `M` | 年均课程日历片段数 |
| `Y` | 在线保留学年数 |
| `U` | 峰值并发用户数 |
| `E` | 单次最大导出行数 |

存储测算至少包含原始层、标准层、聚合层、索引、备份和重算临时空间；建议按实测压缩后容量的 2～3 倍预留。课程日历和成绩尝试通常是主要增长表，应单独分区并验证历史查询。

## 4. 待学校确认的服务指标

| 指标 | 需确认内容 |
|---|---|
| 页面响应 | 普通查询 P95、复杂聚合 P95 |
| 并发 | 日常和选课/评估高峰并发 |
| 数据时效 | 学籍、成绩、教学任务、课程日历各自刷新频率 |
| 可用性 | 月度服务等级及计划维护窗口 |
| 恢复目标 | RPO、RTO |
| 导出 | 最大行数、异步阈值、文件保留时间 |
| 留存 | 明细、聚合、审计和日志保留年限 |

## 5. 性能验证

- 使用脱敏且规模等价的数据集压测，不使用少量原型数据推断生产性能。
- 覆盖登录、学期元数据、学生详情、课程列表、热力图、课程团队、教师分布和报表导出。
- 分别测试冷缓存、热缓存、单用户、目标并发和峰值并发。
- 记录 P50/P95/P99、错误率、数据库耗时、扫描行数、缓存命中率和资源使用率。
- 对跨学期成长轨迹、课程日历和成绩有效结果建立专项慢查询基线。

## 6. 数据验收

### 6.1 批次验收

- 文件数、记录数、主键数和校验和一致。
- 代码值覆盖率、必填完整率、关联成功率达到签版阈值。
- 隔离记录有规则代码、源标识和处理责任人。
- 批次可重复执行且结果幂等。

### 6.2 业务对账

- 每个数据域选择正常、边界和异常样例。
- 成绩对账覆盖正常、补考、重修、缓考、作废和更正。
- 培养方案对账覆盖已完成、未通过、未到期和无完成证据。
- 教学运行对账覆盖普通、体育、思政、单双周、调课和跨学院课程。
- 对账结果由学校业务负责人签字确认，不能只由开发团队验证 SQL 行数。

## 7. 功能与权限验收

- 按需求编号建立需求—页面—API—字段—规则—测试链路。
- 每个角色验证正常访问、越权参数、直接 URL、导出和历史数据范围。
- 辅导员、导师、任课教师等动态关系必须验证生效时间。
- 敏感明细、聚合和导出分别授权。
- 预警闭环功能不在当前验收范围，除非产品范围后续确认。

## 8. 安全验收

- 接入学校 SSO，禁用演示账号和默认密码。
- 强制 HTTPS、密钥轮换、最小权限数据库账号和依赖漏洞扫描。
- 检查注入、越权、批量枚举、恶意导出和日志泄密。
- 学号、姓名等个人信息按角色脱敏；测试数据同样受控。
- 管理员及敏感明细访问进入不可篡改审计。

## 9. 可观测性与运维

必须监控接口成功率和延迟、数据批次状态、质量规则命中、任务积压、数据库连接、存储增长和备份结果。日志携带 `trace_id`、用户、数据范围和数据版本，但不得记录令牌、密码或无关个人敏感字段。为同步失败、质量门禁失败、聚合过期和容量阈值建立分级告警。

## 10. 备份与灾难恢复

- 分析库、配置、审计和文件分别制定备份策略。
- 定期执行恢复演练，不以“备份任务成功”替代可恢复验证。
- 原始批次在保留期内可重放；派生聚合应能由标准层重算。
- 灾难恢复后核对数据版本、批次完整性和权限配置。

## 11. 上线门禁

上线前必须同时满足：

1. P0 业务口径由学校签版。
2. 数据契约和代码表签版。
3. 目标规模性能测试通过。
4. 全角色权限和越权测试通过。
5. 数据对账和用户验收通过。
6. 安全扫描无未接受的高危问题。
7. 备份恢复、发布回滚和故障演练完成。
8. 运维责任、告警接收人和应急通讯录明确。

## 12. 交付物

- 签版 PRD、数据字典、指标字典和 API 文档。
- 数据同步、质量、血缘和补数说明。
- 数据库迁移脚本和回滚说明。
- 自动化测试、性能报告、安全报告和 UAT 记录。
- 部署手册、监控面板、备份恢复和故障处理手册。
- 已知限制、遗留问题和下一阶段路线图。
