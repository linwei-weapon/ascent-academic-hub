## 3. 字段和路径规则

| 字段 | 含义 |
| --- | --- |
| current.routes | 当前前端路由，区分 page 和 redirect；动态重定向回到 router/index.ts 核对 |
| current.viewFiles | 模块归属的现有 Vue 文件，包含子组件、抽屉及可能保留的兼容页面 |
| current.requestHelpers | 已有请求或展示辅助位置，尚不表示已经形成统一 API 层 |
| current.typeFiles | 已定位的独立接口或相关定义文件；空数组不表示没有局部类型 |
| current.backendFiles | Router、分析、加工和辅助文件；同一文件可服务多个模块 |
| current.apiGroups | 实际 APIRouter 容器和声明前缀，不是完整端点清单 |
| current.dataSources | 引用 dataSourceDefinitions 中的逻辑来源 ID |
| current.documents | 相关原文路径，只建立引用，不修改内容 |
| current.relevantTests | 可参考的现有测试入口，本轮没有执行，也不承诺列表覆盖全部验收 |
| target | 后续建议目录或文件，status 为 not-implemented；不得当成现有文件 |
| sharedDependencies | 公共能力 ID，方便识别影响范围，不参与运行时依赖注入 |
| applicationRoutes | 根重定向、通配重定向和 /admin 布局等应用级路由 |
| unassignedViews | 未归入当前业务入口的文件，标记需要消费者核对 |
| supplementaryRouters | 通过公共能力复用，或仍需核对消费者的 Router |

源码、文档和测试路径相对于仓库根目录；runtimeLocation 是运行数据的预期位置或配置说明，不要求源码副本中存在。数据源仅登记连接和配置证据，不记录数据库内容、用户信息或密钥。

## 4. 公共能力

- **HTTP传输（transport）**：JSON和下载已有封装；部分fetch与SSE仍有独立处理。 入口示例：[http.ts](../../code/frontend/src/utils/http.ts)。
- **工作身份与权限（identity）**：菜单、动作、明细、比较和人员关系授权。 入口示例：[auth.ts](../../code/frontend/src/store/auth.ts)。
- **路由与应用外壳（routing）**：路由、兼容地址和应用入口。 入口示例：[index.ts](../../code/frontend/src/router/index.ts)。
- **筛选元数据（metadata）**：按接口当前语义核对缓存和范围。 入口示例：[meta.ts](../../code/frontend/src/utils/meta.ts)。
- **数据与指标公共实现（data）**：V2 Router为多业务共用容器；schema与迁移共同描述结构。 入口示例：[db.py](../../code/backend/api/db.py)。
- **公共组件和主题（ui）**：复用现有组件，不以索引替代组件API。 入口示例：[components](../../code/frontend/src/components)。
- **教学洞察与兼容专家（ai）**：旧ai.py仍服务教学页面；不得整体认定为无用。 入口示例：[ai.ts](../../code/frontend/src/utils/ai.ts)。
- **安全、审计和运行入口（audit）**：仅定位现有实现，不代表本次已验证运行或权限。 入口示例：[main.py](../../code/backend/api/main.py)。

当前业务链路可概括为“页面 / 现有 utils helper → HTTP / 部分直接 fetch → Router → 现有分析或查询 → 数据”。目标 API 层未创建，不能将索引视为已完成迁移。

本轮没有把 `D:\\ascent-academic-hub` 的数据库复制到新项目。GitHub 克隆能看到连接代码，不代表已有相应数据文件或可运行结果。各模块的 dataSources 表示源码依赖类别，不是完整字段血缘；具体指标使用哪个来源仍以对应查询和指标文档为准。

## 6. 必须保留的跨模块关系

- 学生详情旧接口在 alert Router，新接口在 V2；不能按文件名把学生详情全部归预警。
- 低年级受挫 Vue 文件保留在 reports 下，但由预警工作区引入；毕业准备文件由培养质量引入；课程质量文件由教学运行引入。
- V2 Router 是多个模块共用的实现容器。拆分一个业务时先核对所有消费者，不将“V2”当作产品菜单。
- ai_decision.py 同时承载决策/问策和学校方案配置，因此 decision 与 system 均登记。
- settings.py 同时承载规则及其他配置，预警规则仍归预警工作区。
- 基础报表共用一个 Vue 页面和目录定义，但有九条路由；验证与后续 API 试点需覆盖九张报表。
- 旧管理要情、决策研判、培养方案详情、师资详情等兼容重定向保留在 current.routes 中，不能因新入口存在直接删除。
- 路由文件存在不等于角色拥有菜单或后端数据权限；本轮没有访问实际授权菜单。

## 8. 覆盖范围与使用限制

本索引覆盖 views 目录 **65 个 Vue 文件**（含模块文件、应用布局及待核对文件），前端 **65 条路由声明**（含兼容跳转和布局），后端 **20 个声明了 APIRouter 的容器**。辅助 Python 文件不会因位于 routers 目录就被误计成独立 Router。

测试目录现有 56 个 test_*.py，相关入口已按模块登记；这是静态定位，不是测试通过数量。本索引不是逐端点 API 文档，也不是完整组件依赖图。

新增内容的维护继续遵守用户的原文保护前提：若补充模块归属或步骤状态，在文件名含“新增”的文档中记录；不得因旧约定要求同步原文而直接覆盖受保护文档。现有代码行为的变更另按后续步骤验证。
