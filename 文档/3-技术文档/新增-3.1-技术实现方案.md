# 3.1 技术实现方案

> 新增技术正文，2026-09-14。描述当前可从源码核对的机制及后续整理要求；不把建议目录、历史验收和外部部署状态当成当前事实。

## 一、前端初始化与路由

main.ts 创建 Vue 应用、初始化状态和路由、加载样式并注入 Style A。路由使用 Hash 模式，后台布局承载业务页面；证据核验页独立于主布局，用于新开窗口。

路由守卫检查登录、可见菜单和当前身份授权。旧菜单地址通过重定向指向现有工作区，例如培养进度并入培养质量，旧 AI 要情/研判并入决策简报。兼容地址需要保留来源参数，不能仅重定向路径而丢失用户正在查看的对象。

认证和角色状态保存在现有 store 中，不假定已经全部改用 Pinia。菜单来自服务端授权结果；索引文档和前端路由不能代替后端授权。

## 二、普通 HTTP 请求

公共 http 接收去掉 `/api` 的业务路径，统一补前缀并附加 token 和当前身份，读取 `{code,msg,data}`，向调用方返回 data。页面主要处理加载和渲染，后续逐步将端点和参数组织移入命名业务 API。

401 表示认证不能继续，按公共流程清除令牌并转登录；非零 code 表示业务失败。文件与 SSE 有各自的响应处理，不能对任意成功 HTTP 响应都执行相同 JSON 解包。

现有 utils/meta.ts、部分导出和 SSE 存在独立 fetch，公共链路尚未覆盖全部请求。整理时逐一核对认证头、身份、失败状态和缓存，不用全局字符串替换冒充等价迁移。

## 三、身份与权限解析

后端依赖解析 Bearer JWT，验证用户状态及令牌撤销信息，然后依据 `X-Active-Identity` 获取有效工作身份，生成 permissionContext。身份 ID 需要属于当前账号且在有效期内。

上下文分别表达菜单、动作、明细范围、聚合比较范围及字段策略。对象详情、证据、文件下载和 AI 会话均重新验证。学院可以比较的范围不能直接作为学生查询范围。

人员范围依赖组织授权和有效人员关系；导师、班主任、辅导员使用相应关系类型，不因关系缺失退回全校。请求缓存必须带实际范围标识，角色相同但带班不同的用户不能共用学生明细结果。

## 四、在线查询与加工的分工

在线接口对已经加工的事实和聚合执行有界查询；需要批量清洗、绑定和重算的工作由 ETL 执行。普通页面读取不能隐式触发整个数据初始化。

旧库与 V2 通过不同只读连接访问。平台治理操作使用显式可写连接，提交和错误回滚清晰。部分报表需要读取学期源库，因此运行检查须核对相应配置和输入，不能只检查两个输出文件。

Router 当前常含查询和计算；后续仅在具体业务任务中提取 service/query。跨模块共用正式计算向下复用，不能通过 Router 相互调用形成循环。

## 五、缓存与数据一致性

已有查询缓存和 AI 简报快照按模块实现，不能声称所有缓存规则完全统一。核对缓存时需要列出输入：用户/身份、范围、周期、筛选、数据版本、指标规则及学校方案版本。

更新数据、切换身份或发布方案后，不能继续把旧范围或旧规则结果展示为最新。一个页面同时请求指标和名单时应维持相同已应用条件；较晚完成的旧请求不得覆盖新查询。

基础报表导出使用结果快照，服务端核对当前条件、权限和数据对应关系。错误、失效或不匹配的快照应要求重新查询，不生成与页面不同的文件。

## 六、AI 分析与流式问策

SkillContext 包含用户、双库连接、生效配置和学期；Skill 声明所需数据、白名单参数和数据边界，输出事实信号。信号包含对象、严重程度、关键数字、建议、置信说明和证据。

简报引擎运行 Skill、合并与排序信号、比较快照并组织页面内容。四类当前 Skill 为毕业缺口、课程质量、预警优先级和师资结构。模型增强用于解释，失败时通过规则输出和状态披露降级。

专家问策通过 POST SSE 返回 meta、delta、done、error 等事件，维持专家与会话上下文。打开信号证据时走独立只读页面，服务端再次验证范围。旧追踪接口的兼容退役响应不能作为实现办理闭环的依据。

学校分析方案仅允许覆盖配置白名单参数，发布前进行数据就绪检查和影响试算，按角色选择有效版本。方案不得携带任意 SQL、正式指标公式或组织范围来绕过公共授权。

## 七、错误与审计

后端使用统一 ApiError/包络返回可读错误，未捕获异常在服务端记录，客户端不显示堆栈。审计记录敏感访问、导出、管理配置与适用的 AI 运行事件，日志避免记录凭证及学生敏感正文。

查询失败、数据未接入和结果为空分别处理。真实接口异常时不能静默启用 Vite 的旧 Mock，也不能将失败后的模板回答展示为模型成功生成。

## 八、运行和验证边界

开发前端通常在 3006，API 在 8000；Vite 当前固定代理到 IPv4 回环地址。前端构建存在时 FastAPI 可以同源托管 dist。启动脚本、隐藏 helper 和构建脚本仍按现有实现使用，不因本文件新增就发生变化。

代码整理验收应覆盖普通查询、身份切换、名单下钻、导出、简报、问策和异常恢复；类型检查与构建分别报告。此次文档工作未启动服务或调用模型，当前运行能力需要在下一阶段建立基线。
