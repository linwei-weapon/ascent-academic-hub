# 公共表格与分页组件说明

AppTable 基于 Element Plus，配合 AppPagination 使用，已覆盖系统管理的 18 处表格（含标签页与抽屉子表）、基础报表的 9 张主表，以及教学管理分析现行入口的 80 处表格。本文是该组件的统一说明，后续功能直接在本文完善。

[表格组件可视化规范](../2-样式规范/新增-2.1-表格组件可视化规范.html)：直接打开 HTML，查看基础结构与密度对比、组合示例及当前页面接入清单。样稿使用独立示例数据；后续在同一展示页完善。

Element Plus 在 [main.ts](../../code/frontend/src/main.ts) 中通过 `app.use(ElementPlus)` 全局注册，并统一加载完整样式。项目组件继续显式引用或由 Vite 的 Components 插件自动引入；`types/import/components.d.ts` 只是自动生成的项目组件类型提示，Element Plus 类型由 `tsconfig.json` 中的 `element-plus/global` 提供。`ElMessage` 等脚本调用仍显式 `import`，与全局模板组件注册分工不同。

## 支持的功能

| 功能 | 说明 |
| --- | --- |
| 列设置 | 显示/隐藏列、拖拽或按钮排序、必选列保护、业务列数量限制、恢复默认。 |
| 自适应宽度 | 数据列按最小宽度比例铺满剩余空间；隐藏列和调整窗口后自动重排；窄屏横向滚动，支持左右固定列。账号操作列固定为 130px。 |
| 三档密度 | 紧凑、默认、宽松，调整字号和留白，多行内容自然撑开；不改变分页或发起查询。切换项与列设置统一使用 small 尺寸：高 32px、字号 13px、左右内边距 14px。 |
| 表格样式 | 表头居中、内容默认居中，表头使用主题浅靛蓝背景；支持斑马纹及行悬停效果。 |
| 显示偏好 | 按用户、工作身份和表格保存列显隐、顺序及密度；刷新后恢复，无效偏好回退默认。 |
| 分页 | 默认第 1 页、每页 20 条，可选 10/20/50/100 条；“共 XX 条”紧邻每页条数选择框，与页码、前后翻页和跳转排列为同一组。加载时禁用分页，空结果隐藏分页。页码输入与翻页按钮高度保持一致，避免纵向滚动条。 |
| 自定义内容 | 支持单元格、表头、工具栏、空状态及 `columns` 自定义列插槽，以及行点击事件和加载状态。分组表头可通过 `columns` 提供原生列结构。 |
| 合计行 | 通过 `show-summary`、`summary-method` 提供汇总内容，按实际列字段映射数值，随列宽和列顺序自动对齐。学院教学供给规模已采用此方式。 |

`toolbar` 插槽位于表格左上角，与右侧密度切换、列设置同排，可放置 small 尺寸的搜索栏、操作按钮或提示内容。已接入学生证据名单的学号/姓名搜索、低年级风险观察中学生核查名单的搜索/查询/重置、学院师资保障概览的学院搜索、开课保障关注 TOP10 的“查看全部”，以及当前预警学生的名单筛选、查询、重置、导出和筛选提示。标题、人数和说明保留在表格上方；工具栏内容较多时自然换行，查询和导出仍使用原有条件与事件。

## 页面接入

- 页面传入 `columns`、当前页 `data`、`page`、`pageSize`、`total` 和 `storageKey`，通过 `page-change`、`page-size-change` 处理查询。组件只展示数据，不请求接口或再次切片。
- 普通列用 `minWidth`，固定宽度列用 `width`；`fixed` 只控制滚动时的固定位置。至少保留一个自适应数据列，才能利用剩余空间。
- 密度切换与列设置分别通过 `showDensity`、`showColumnSettings` 开启，默认均隐藏。替换旧表格时只启用页面原有或已明确要求的功能；账号页两项开启，角色页两项关闭。隐藏密度切换时按 `defaultDensity` 固定展示，隐藏列设置时按页面声明的列布局展示；对应旧偏好保留但不应用，也不覆盖。两项关闭且没有工具栏插槽时，不保留空工具栏。
- 查询、重置、改变页长回到第一页；翻页使用已提交条件。防止旧请求覆盖、错误重试和末页修正由页面处理。

账号页将查询账号区域并入“账号与接入状态”卡片：标题和结果说明位于上方，其下为查询范围提示；账号搜索、五个筛选项及查询、重置按钮通过 `toolbar` 插槽排列在提示下方同一行，密度切换和列设置独占下一行并右对齐。控件保持 small 尺寸，窄屏筛选区按三列、两列或单列换行，查询和重置按钮保持成组。正常进入或刷新从 1/20 开始，不把分页和筛选写入地址栏，也不读取旧页长偏好；显示偏好继续保留。从数据权限返回时，通过一次性内存上下文恢复列表现场。列设置的“恢复默认”只恢复列布局和密度。

账号详情通过“用户与账号”列中的蓝色姓名或登录账号打开，两行都支持鼠标及键盘操作，保留姓名加粗、账号小字的层级。悬停姓名与账号区域时，两行同时显示下划线，移开后取消；其他文字与行空白区域不触发详情，操作列只保留“更多”。缺少有效账号标识时，两行都显示为灰色普通文字，不出现链接下划线。现有有效账号均沿用原查看权限，不依据其启停或映射状态限制查看。

角色页使用原接口返回的完整列表，在页面按服务端顺序分页，组件不重复切片。进入或刷新从 1/20 开始，翻页和切换页长均不重新请求接口或写入 URL。使用默认行距，隐藏密度切换与列设置，固定展示全部六列；名称和操作列支持横向滚动固定，操作列为 320px。保留新建、编辑、删除、配置权限和权限预览；保存后保留当前页，删除后校正失效末页。

其他系统管理表格沿用以下接入方式；表格默认使用默认档行距，业务单元格、按钮、筛选和详情操作仍由页面提供。

| 模块 | 表格与分页 | 密度和列设置 |
| --- | --- | --- |
| 菜单管理 | 保留树形展开、父子顺序与编辑操作，不分页拆分菜单树；一级编号位于排序表头正下方，子级中心向右缩进 16px，原生箭头紧贴编号左侧，编号按实际文字宽度展示。该列最小宽度 120px，缩进与编号不换行，窄屏保留横向滚动；其他列仍居中。 | 隐藏 |
| 数据权限 | 账号名单在前端分页，摘要仍根据完整列表计算；带班与带生关系使用服务端分页。 | 隐藏 |
| 审计日志 | 保留操作筛选，使用服务端分页。带时区的日志时间统一按北京时间显示为 `YYYY-MM-DD HH:mm:ss`，隐藏 `T` 和时区后缀，原始记录不变；空值显示 `—`，无时区历史值保留原时间。 | 隐藏 |
| 指标与口径管理 | 指标目录使用服务端分页，页面引用在前端分页，详情变更记录不分页；候选指标提示位于目录表格卡片上方，搜索筛选和查询、重置按钮放在表格 `toolbar` 插槽，与右侧密度切换和列设置同排；搜索框固定为 260px，空间不足时换行。指标名称和编号使用主题蓝色标记详情入口，悬停时两行同时显示下划线。 | 目录、页面引用保留；变更记录隐藏 |
| 分析方案管理 | 草稿与版本历史分别在前端分页，保留原发布、检查和回滚条件。 | 保留 |
| 数据采集监控 | 数据源和运行列表使用服务端分页；接入清单、最近批次、关联运行和输入批次分别在前端分页。运行与异常的说明提示位于卡片内筛选栏上方，任务和状态筛选与右侧显示设置同排；其他主标签页的筛选或提示保留在表格左侧工具栏，窄屏自然换行。 | 保留 |
| 账号认证来源 | 抽屉内完整展示，不分页。 | 隐藏 |

系统管理系统管理新增接入的分页表格统一从 1/20 开始，页长可选 10/20/50/100；原列与密度偏好使用原存储标识和版本，旧页长不参与恢复。全量列表复用 [useTablePagination](../../code/frontend/src/composables/useTablePagination.ts)，保留原完整数据用于统计与业务操作，只把当前页切片传给组件；集合重载或筛选后回第一页。系统参数仍为表单；旧 `DecisionConfig.vue` 已无菜单入口，其路由继续重定向到分析方案管理。

基础报表九张主表统一使用 AppTable，保留整表展示，不增加分页，以免拆开合并单元格和汇总行。八张通用表保留密度、列设置及原偏好标识和版本；课程补考对比继续隐藏这些工具，通过 `columns` 插槽保留两层表头、12 个叶子列和课程合并。使用自定义列时由页面提供完整列结构与居中配置，关闭列设置。百分比精度、公式提示、前三名标识、课程证据、查询条件与快照导出沿用原行为。来源规则折叠区也使用 AppTable，原显示条件不变。入口：[通用报表表格](../../code/frontend/src/views/basic-reports/components/BasicReportTable.vue)、[课程补考对比表格](../../code/frontend/src/views/basic-reports/course-makeup-comparison/CourseMakeupComparisonTable.vue)。


教学管理分析六个菜单及详情子表已统一接入，现行入口共 80 处；另外 11 处未开放的历史视图或方案结构子表也完成代码替换，原显示条件不变。原 DataTable 表格保留密度、列设置及偏好标识；原生子表使用 `columns` 插槽，隐藏两项工具。表头与内容居中，普通列按最小宽度自适应，操作列保留必要宽度。

| 模块 | 覆盖内容 |
| --- | --- |
| 教学数据总览 | 学院比较、学院与专业下钻、年级课程、课程班级分布；共用历史指标、年级课程及预警学生弹层。 |
| 学业预警监控 | 预警名单、低年级风险的年级/课程/专业/学生表、规则与变更、候选名单及影响分析。 |
| 教学运行分析 | 开课供给、排课结构、教室占用、教师负荷、调停课、课程结果及相关明细。 |
| 培养质量分析 | 学院/专业执行、课程瓶颈、核查名单与证据、学生进度、毕业准备及课程保障。 |
| 师资保障分析 | 学院保障、课程核查队列、课程团队与教学班、教师当前课程及历史。课程核查队列的核查类型、课程搜索、查询与恢复全部放在 `toolbar` 左侧，与右侧密度切换和列设置同排；按钮保持 small 自然宽度和 8px 间距。 |
| 学生成长与学业分析 | 组织比较、关注名单、学生清单与详情、带班/带生学生以及公共学生证据抽屉。 |

分页保留页面声明的初始页长和服务端查询方式，不从旧显示偏好或新增 URL 参数恢复页长；本地分页允许显式保留 10/20 条初值。服务端名单只把当前页交给组件，翻页或切换页长各查询一次；完整列表由 `useTablePagination` 切片。带班列表的每个展开班级独立持有页码。原本不分页的表格继续完整展示，规则交叉表保留合并逻辑；固定 20 条的候选接口只提供 20 条选项。

本轮只整理前端表格展示与分页接入，指标名称、计算逻辑、管理用途、数据来源、适用边界及核查路径保持原定义。教学分析核查入口见[路由](../../code/frontend/src/router/modules/teachingAnalysis.ts)；原指标确认书正文按原文保护要求保留。
