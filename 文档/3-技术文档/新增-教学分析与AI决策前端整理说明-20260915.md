## 1. 本次规格与边界

教学管理分析按教学数据总览、学业预警监控、教学运行分析、培养质量分析、师资保障分析、学生成长与学业分析六个菜单组织到 `views/teaching-analysis/`。AI 管理决策按决策简报、专家问策和独立证据页组织到 `views/ai-decision/`。现有子页面、抽屉与专用组件随所属模块归类。

保留当前 URL、兼容重定向、菜单授权、工作身份、筛选与分页、请求参数、指标口径、CSV 和 SSE 协议。业务请求逐步归入对应 API 模块；展示工具仍由 utils 承担。补充关键流程注释，将局部样式整理为有层次的 SCSS，并核对编译后的样式一致。

旧 `settings/index.vue` 是预警规则治理页面，归入学业预警；三个旧 reports 事实专题分别归入预警、教学运行与培养质量。没有接入菜单的实践教学空态归入培养质量，继续保留原状态。学校管理与旧同步页面不属于本次两个业务分组，保留原位置。

本次不调整后端业务实现、数据库、正式指标、模型配置或学校数据。既有 Python 源码契约测试中受影响的前端路径与实现定位随迁移调整，测试业务要求保持。新增疑点登记到补充待办，登记不代表已获授权修改。

## 4. 路由、请求与类型

`router/index.ts` 继续负责创建路由、注册 Layout、错误恢复和统一权限守卫。`router/modules/teachingAnalysis.ts` 维护教学分析及旧事实专题的重定向，`router/modules/aiDecision.ts` 维护简报、问策及其兼容入口；独立查证路由从同一 AI 文件单独导出，在根路由注册。没有更改后端菜单路径，也没有新增一套权限判定。

教学运行六个 URL 继续引用同一 Index 组件，共享统计学期、数据上下文和已加载专题。培养质量与预警保留原标签、懒加载和 URL 查询参数。AI 证据页继续独立打开，不挂载管理端 Layout。

普通请求由页面调用模块 API，再使用原 `utils/http.ts`。API 保留参数编码、可选参数、静默请求、分页限制及空 body 语义；页面继续负责加载状态、已提交条件、请求序号、结果赋值和用户反馈。没有将旧 DTO 统一改名，也没有在前端重算后台指标。

普通教学洞察归入 `api/teachingAnalysis/insights.ts`；筛选元数据与教学学期归入 `api/shared/filterMeta.ts`、`teachingMeta.ts`。原 `utils/ai.ts`、`meta.ts`、`v2meta.ts` 通过兼容导出复用同一实现，避免产生两份进程缓存。

原 `utils/decision.ts` 的业务请求拆为简报、问策、证据、配置四部分，窗口导航仍留在 utils，并保留所有旧请求导出。`api/aiDecision/configuration.ts` 供系统管理共用；本轮没有移动或修改系统管理页面。原学校配置接口类型提取到 `types/decisionConfig.ts`，问策事件回调类型提取到 `types/advice.ts`，现有 `types/decision.ts` 保留。

CSV 请求返回原始 Response，由原页面处理状态、Blob、文件名和人数。SSE 保留原 POST、Bearer、工作身份头和 meta/delta/done/error 解析，未替换为普通 JSON 包络。共享缓存、候选导出身份头和不完整流的既有差异已登记待办，目录迁移没有改变这些兼容行为。

48 个 Vue 文件保留原模板与可见内容；48 段样式转换为 SCSS，按相邻根选择器组织后代元素和状态，保留声明顺序、响应式条件、颜色与原作用域。嵌套控制在三层以内，未引入新的主题或全局主色。师资抽屉原有的一段全局遮罩规则继续保持全局，避免改变 Teleport 弹层交互。动态绑定和既有行内样式本轮保留，避免改变优先级。
