开发由Codex完成。第13.8节划定范围，第13.11节分解首批与五专家后续任务，第13.12节规定验证、外部缺口及中断续做。代码开发、真实数据、业务确认和发布分别记录；资料不足只阻塞相关正式能力，仍可推进开发与夹具。取消人工人员、人日与按天排期。
