## 1. 默认研究工作区

![默认研究工作区](D:/AI教育/AI学业助手/10-管理端原型/20260626智能学业分析平台-交接/智能学业分析平台-交接/docs/expert-design-v2-20260915/assets/01-workspace.png)

本图确认的关系：全局菜单保留；局部左栏以我的研究为主、参与专家为辅；中间是主要阅读和讨论区域；研究小结紧凑可展开；资料与个人意见按需打开；输入区加大。

图中文字为资料尚未齐备时的示意回答，因此没有伪造正式数字。完整资料齐备时，应按业务分册输出具体课程、条件或方案影响，不能长期用原则性文案代替业务结果。

图中的示意头像、时间和某某大学均不代表真实人员、运行耗时或实际部署。附加图形不构成新增业务需求，最终以交互规格为准。

## 2. 添加专家状态

![添加专家](D:/AI教育/AI学业助手/10-管理端原型/20260626智能学业分析平台-交接/智能学业分析平台-交接/docs/expert-design-v2-20260915/assets/02-add-expert.png)

本图确认的关系：添加专家使用独立居中选择窗，保留后台研究状态；按职责找专家；已加入与待加入可辨；加入本次研究不自动分析；实际可做什么取决于资料与规则。

五位仅为首批目录。后续专家扩展仍使用同一搜索和加入机制，不将整个目录固定铺在左栏。

点击建议补充或专家说明中的请他补充后，问题先进入输入区，经领导发送再执行。图片只能表达布局，不能证明该行为已实现。

## 3. 收起侧栏与个人意见：结构约定

    原系统导航 │ 展开研究栏 · 当前研究标题/切换研究
               │ 当前范围 · 本次参与专家 · 添加专家
               │
               │ 主对话与分析结果       │ 相关资料 / 我的意见
               │ 可展开的研究小结       │ 个人文字、来源关联
               │ 方案比较放主区域       │ 保存状态、历史版本
               │                        │ 整理讨论材料
               │ 较大讨论输入区         │ 先预览再保存或下载

侧栏收起不影响研究数据。辅助面板并排的前提是主文仍可读，否则覆盖式打开。资料和意见在同一面板切换，保留编辑内容、选区及阅读位置。系统不会因为新分析自动改写个人意见。

## 4. 视觉评审不只看首页

后续可点击原型必须覆盖验收分册S01—S18：空态、范围澄清、默认完成、专注收起、专家选择、定向补充、联合分析、资料定位、方案比较、意见采纳、编辑、多窗口冲突、跨研究切换、研究恢复、部分失败与停止、资料更新、归档恢复和窄窗口。

关键交互应组成连续示例：提出专业建设问题→明确版本→获得判断→查看资料→请另一专家补充→质疑修正→比较做法→写下个人意见→切换研究→回来继续→整理材料。

本次已交付静态图片及完整状态规格；没有把图片描述成可点击原型。焦点、输入法、滚动、保存、恢复、并发与权限必须在后续原型和系统中实际验收。
