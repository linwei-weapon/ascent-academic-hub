# 交互状态与文案规格

版本V2，2026-09-15。独立UX审查经主代理统一后的完整规格。本文描述目标行为，不代表页面已经实现或通过操作验收。

## 1. 固定骨架与布局

左栏默认展开、右栏默认关闭。左栏上部是我的研究、新建、搜索、近期和归档，下部是本次参与专家，不使用任务—专家—场景多层树。主区域显示题目、范围、紧凑可展开研究小结和连续讨论。

资料与个人意见共用一个右侧辅助面板，切换保留文字、选区、滚动和保存状态。添加专家用居中选择窗，不抢走正在编辑的意见。方案比较放主区域。

正文约16px，以640—820px为可读宽度起点；并排不能保留约600px正文时，右面板覆盖式打开，不改变用户左栏偏好。窄窗口左栏作为抽屉。关闭面板回到原触发焦点和阅读位置。

输入默认约四行，增长至约八行后内部滚动。侧栏收起后仍可切换研究、查看参与者和添加专家。首轮不重复显示大块小结卡片，研究恢复或长讨论时可展开小结。

## 2. 逐操作契约

### O01 新建研究

入口为左栏新建研究。显示这次想研究什么及少量业务示例，不先配置专家。第一次发送才创建正式研究和建议标题，避免空任务堆积。

新研究不继承上一项专业、学生和年度，只使用当前合法身份及明确组织范围。同身份保留一个未发送新研究草稿，已有研究各自保存草稿。

切换前尝试保存当前输入，失败则保留文字并提示；返回原研究恢复原阅读位置。空白页不生成新任务。

### O02 范围澄清与修改

只补问会影响结果的对象、版本、学期等关键条件，提供业务选项并允许文字回答。推定范围以暂按某范围分析明确显示。

点击范围说明编辑；关闭不改变生效范围，提交后创建新范围快照和新轮次，历史保留原标识。忙时可准备新范围，但不能就地改写本轮；明确选择停止后重做或等待完成再提交。

### O03 普通提问与忙时操作

回车换行、点击发送或Ctrl+Enter提交，IME组合状态不能误发。空白和重复点击不产生重复轮次。

同研究一次一个主动分析，忙时仍可编辑下轮草稿、查看资料、切换研究。普通发送说明当前轮次未完成，不隐式排队；停止后发送须明确操作含义，已写文字不丢失。

服务端确认后显示问题已收到，网络不确定时沿用同一请求标识重试。用户正在向上阅读时不强行滚到底部。

首次未选专家由系统匹配主答并明示；已有研究只安排已加入且与本轮有关的专家，不让所有专家逐个报到。需要新专家时提出具体补充建议，经用户发送确认后加入执行。本轮结果只署实际参与者，参与列表与本轮发言不是同一概念。

### O04 添加专家

入口在左栏和收起状态主区顶部。居中窗含搜索、职责、适合问题、已加入状态和当前资料可支持范围；不展示模型参数或技术配置。

加入本次研究只保存参与关系，不立即分析、不改变下一轮模式。忙时允许加入并说明后续生效，本轮参与快照不变。关闭后恢复原研究位置和焦点。

### O05 定向补充

从专家说明的请他补充，或回答下方具体建议进入。问题先填入输入区，显示本次请某专家补充，可修改或取消。用户发送后执行。

未加入专家可随本次发送加入，发送前说明。定向仅本轮有效，发送成功后回到普通问题处理，不留下隐藏永久模式。专家不支持则说明职责或资料边界，不冒名回答。

### O06 查看与移出专家

点击名称只查看职责、适用边界与本研究已有贡献，不切换对话。移出只影响后续参与，不删除历史，并可短时撤销。

运行期间移出需明确提示本轮仍保留该专家参与、后续不再参与；不自动取消。停止本轮是另一个动作。目录停用也保留历史版本和来源。

### O07 资料定位与返回

从段落、表行或计算说明进入，直接定位本轮采用的原文段落、课程记录、规则条款或分子分母。顶部查看资料提供本研究资料目录。

默认读实际使用版本；有新版本只提示，不冒充旧分析来源。加载中、缺资料、无权限、已更新分别说明。没有真实入口时不提供假的查看按钮。

关闭后回到触发段落及焦点；不套第二层抽屉。服务端重新鉴权，拒绝时不能顺带展示敏感摘要。

### O08 比较做法

从具体建议或自然语言提出。仅在比较对象不明时澄清。主区域对照现状与拟议做法，包含解决问题、影响范围、课程/学分、资源条件、实施风险。

未知项为待确认，不补虚假评分或成本。比较是一轮结果，不新建任务；可调整假设、收起回原轮次、选择内容纳入意见。

### O09 领导质疑与补充

用户直接说明与实际不符，或在判断处补充情况。定位原来源，分开资料记载与领导补充，说明影响哪个判断。

允许明确假设下继续，将需正式确认内容保留待确认。不回写源库，不把口头补充固化为正式事实。旧分析确需修正时保留原版本和原因，不能用重新生成替代修正链。

### O10 纳入我的意见

选取内容或点击纳入我的意见后，先预览文字和插入位置。默认追加，不覆盖全文；替换某段或整篇整理须明确展示变更后采纳。

采纳不代表接受本轮全部建议。保留来源关联，定位插入处并支持撤销。用户可完全自行撰写，不要求先生成草稿。

### O11 编辑与自动保存

短延迟自动保存，失焦或切换时立即尝试。只有服务端确认才显示已保存。输入草稿、意见、元信息、参与者各自版本，不被无关更新打断。

保存失败保留文字、显示暂未保存并可重试；关闭面板不丢草稿，离开应用仍未保存时提醒。不默认把敏感文字持久写入不受控本地存储。

### O12 多窗口冲突与版本恢复

提示这份意见已在其他窗口更新，你的文字已保留。可查看另一版本、合并后保存、保留为新稿，不自动最后写入覆盖。

历史可看、可恢复；恢复作为新版本，旧版本保留。摘要压缩、新分析、专家移出和资料变化均不得自动改写个人意见。

### O13 切换、搜索与恢复

范围、参与者、草稿、意见、阅读锚点和辅助面板状态按研究保存。忙时可切换；新结果只归所属研究，在列表轻提示，不抢当前焦点。

同次切换恢复原位置；较久打开可选择继续上次位置或看最新小结；搜索进入定位匹配内容并提供回到最近讨论。鉴权前不先露出旧缓存。

搜索覆盖全部授权研究，不止前端近期50条。标题用实际业务问题，支持重命名和合理换行，不用难懂缩写。

### O14 归档与恢复

归档移出近期，不删除资料、意见和材料；已归档可查、可恢复，恢复仍鉴权。

忙时不能静默归档，提示分析进行中，可返回或停止并归档。一轮完成不自动标记整项研究完成。

### O15 整理讨论材料

选择本研究有用内容与意见版本，先预览再保存/下载。没有个人意见可形成研究材料，但不虚构领导观点。

保存主题、范围、时间、规则、来源及未明确事项，固定为时点成果；新分析不回写旧材料，重新整理另存版本。下载再鉴权，不自动发送，不代替审批或执行。

## 3. 全状态矩阵

| 状态 | 反馈及可做操作 | 必须避免 |
|---|---|---|
| 无研究 | 提问、少量例子、了解专家 | 假数字填空页 |
| 未发送草稿 | 尚未分析，可编辑恢复 | 空任务堆积、丢字 |
| 条件待明确 | 一个具体问题，可选可答可取消 | 大量配置表 |
| 已提交待处理 | 已收到或真实排队，可写草稿切换取消 | 重复建轮次 |
| 正在分析 | 真实阶段，历史可读，可查资料切换停止 | 全页锁死、假百分比 |
| 本轮完成 | 业务回答与具体下一步 | 只有长报告无后续 |
| 部分完成 | 成功和失败贡献分列，可重试失败部分 | 伪装完整共识 |
| 取消中 | 正在停止，可看历史切换 | 把收到取消当已停止 |
| 已停止 | 边界清楚，可修改重试 | 迟到内容改写小结 |
| 失败或超时 | 未完成及恢复入口，保留问题 | 猜测原因、清空进展 |
| 资料不足 | 缺什么、影响什么、还能做什么 | 整位专家一律不可用 |
| 专家暂不可用 | 说明影响，可用其他能力或稍后重试 | 其他专家冒名回答 |
| 资料已更新 | 保留旧结果，可查看新版和重算 | 新来源冒充旧依据 |
| 领导补充与资料矛盾 | 两者分列，可条件性讨论 | 盲从或固执重复 |
| 身份或权限变化 | 授权通过后呈现，合法切换或退出 | 旧摘要和事件泄露 |
| 正在保存 | 真实状态，可继续编辑 | 未确认报成功 |
| 保存失败 | 暂未保存，文字保留，可重试 | 静默丢失 |
| 多窗口冲突 | 两份保留，可比较合并另存 | 强制最后写入覆盖 |
| 已归档 | 标识与恢复入口，可授权查看 | 等同删除 |
| 长研究 | 分页、全历史搜索、小结索引 | 强制换题、整页全加载 |

## 4. 历史、小结与个人意见

历史按稳定轮次顺序分页，向上加载保持锚点。每轮保留范围、资料版本、实际专家与状态。小结仅依据有效完成结果更新，包含已明确、未明确、分歧和一两个继续方向，并逐项定位原轮次。

小结不代替原资料，不自行推断领导已同意。失败片段不得成为确定判断；用户读旧内容时，小结更新不造成页面跳动。

个人意见引用旧范围时，提示可以查看本轮变化后再决定是否修改，不自动替换。材料读取明确版本并固定保存。

## 5. 中文文案、键盘与焦点

按钮讲动作，状态讲事实。使用分析意见、资料、来源、范围、我的意见、待确认等普通中文。专业规则需准确表达，不为避免AI词牺牲精确性。

| 不建议 | 推荐 |
|---|---|
| 启动智能研判 | 开始分析 |
| 召唤智能体 | 添加专家／请专家补充 |
| 全部专家一致认为 | 写明真实共同判断和不同关注点 |
| 数据不足无法回答 | 缺少某资料影响某判断；现有内容仍可比较某项 |
| 冲突提交失败409 | 这份意见已在其他窗口更新，你的文字已保留 |
| 生成决策闭环 | 整理讨论材料 |

标题应有管理含义，不使用空泛的综合洞察。重要条件就近出现，不以长篇免责说明替代回答。

回车换行，Ctrl+Enter可辅助发送，旁有提示；IME候选组合期间不误发。达到长度限制保留全文并解释，不自动截断。空白和重复点击不重复建轮次。

弹窗焦点进入适当控件，关闭返回触发按钮；Tab顺序符合视觉顺序，Esc遵守保存保护。重要操作键盘可达，状态不只靠颜色，功能不依赖悬停。

新结果和保存不抢编辑焦点。用户向上阅读时停止自动跟随，显示有新内容入口。屏幕阅读器不逐字播报整篇流式正文，完成后给简短通知。

## 6. 18个关键视觉与交互状态

S01新研究空态；S02范围澄清；S03默认完成；S04收起专注；S05添加专家；S06定向补充待发送；S07联合分析；S08资料定位；S09方案比较；S10意见采纳预览；S11意见编辑；S12多窗口冲突；S13跨研究切换；S14研究恢复；S15部分失败/停止；S16资料更新；S17归档恢复；S18窄窗口与125%缩放。

S01—S14组成连续可点击流程，S15—S18做专项验证。静态图片用于视觉确认，焦点、滚动、保存、恢复、冲突和权限必须实际操作，不能说图片已验证交互。

核心验收：领导能提出问题、理解判断、质疑补充、比较做法、留下意见、离开后继续，并始终分清正式资料、分析意见与个人判断。

交互分册正文结束。
