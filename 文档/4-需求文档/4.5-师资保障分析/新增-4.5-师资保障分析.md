# 4.5 师资保障分析

> 现行模块说明，2026-09-19核对。首页、指标口径、下钻、权限与数据未接入状态均以本文和公共指标确认书为准。

## 1. 功能边界与目的

师资保障分析帮助教务处和学院判断课程是否过度依赖单个教师、重要课程的承担团队是否稳定、实际授课教师的职称与年龄结构是否具备分析证据，以及真实在岗人员数据是否足够。输出用于核查教学保障，不用于评价教师个人教学质量。

本模块不根据学生平均成绩给教师排名，不使用模拟年龄、学历、教龄或学缘形成正式结论。单一教师承担课程是需要核查的结构事实，不自动等同于教学质量差或教师能力不足。

## 2. 页面描述

页面先展示统计学期和当前授权范围，再直接展示5张可下钻KPI卡片，随后提供学院比较、优先课程、课程团队及教师教学经历。原首页业务边界提示、旧课程核查KPI、本期管理要点和证据就绪条不再单独占用首屏；相关公式、来源、规则版本和适用边界统一进入KPI tooltip及下钻工作台。

学院比较回答问题集中在哪里；课程清单说明由哪些教师承担、影响多少选课人次；教师任务明细说明当前和历史承担情况。用户能够从汇总进入实际教学任务或团队证据，不能只有一个无法解释的风险分数。

首页指标为：

| 指标 | 业务含义与边界 |
| --- | --- |
| 授课教师总数/教职工总数 | 两项均按真实人员所属组织统计；左侧为承担有效本科教学任务的在岗教职工去重人数，右侧为同期在岗教职工去重人数。真实人员快照未接入时显示“实际授课教师数/—”，不计算参与率 |
| 团队结构异常课程数 | 重点保障课程达到4个教学班或100人次、实际授课教师不少于2人、职称证据完整率不低于90%，但实际授课团队未体现教授或副教授。异常仅表示命中结构核查规则 |
| 连续单点授课教师数 | 在连续单点课程中，对最近3次实际开课至少2次作为唯一授课教师的主要承担者按工号去重；课程仍须满足重点保障与规模条件 |
| 高职称教师授课占比（教授、副教授） | 教授或副教授实际授课教师数÷职称已知实际授课教师数；职称完整率低于90%不输出正式比例 |
| 青年教师授课占比（35岁以下） | 真实人员快照中35岁以下实际授课教师数÷年龄状态已知实际授课教师数；年龄覆盖率低于90%不输出正式比例，不使用模拟年龄 |

缺少联合授课分工比例时，不能把覆盖人数均分为正式教师工作量。

## 3. 核心流程

用户选择学期和授权范围后，可以点击任一KPI打开统一右侧下钻工作台。工作台依次呈现指标值、公式、来源、适用边界、组织分布和服务端分页明细；URL使用`drill`参数保留当前指标。高职称和青年教师指标按课程责任学院展示比例与证据覆盖率，并单列职称、年龄字段缺失治理清单；连续单点指标逐期展示最近3次实际开课的唯一教师证据。点击课程继续进入既有课程团队证据，点击教师进入教学经历证据，返回时保留首页学期和范围。

查看教师任务时，系统展示该教师实际承担的教学班和课程，而非仅显示累计数。由团队、教师再返回列表时保持原过滤条件。跨院比较可以提供聚合，但他院教师或学生明细仍按相应权限控制；学院用户仅因本院课程关系查看外院教师时，前端必须携带该课程证据编号，接口只返回该授权课程范围内的教学经历。

需要管理解释时，辅助分析应引用课程、教师及任务证据，说明单点承担和团队结构为什么值得核查；不能给出未经证实的人事调整结论。

## 4. 异常容错

没有当期教学任务时提示该范围缺少活动证据；教师或职称关系缺失时显示完整性边界，不推定课程无人承担。真实在岗人员快照未接入时，“教职工总数”和“青年教师授课占比”显示为“—/待接入”；职称或年龄证据覆盖率低于90%时不输出正式比例。

查询或抽屉加载失败允许重试，主页面保留原条件。切换学期和学院后的旧请求不能覆盖新对象。没有明细权限时禁止通过URL、指标键或对象ID绕过。统一下钻接口只接受服务端白名单内的5个指标键。

核验时检查概览与下钻是否采用同一学期、学院、异常任务门禁和去重规则，名单或任务合计不能与上层指标矛盾；涉及人员组织口径和课程责任口径差异时必须说明。

## 5. 数据、接口与非目标

`dim_staff_employment_snapshot`承接学校真实人员学期快照，包括人员、组织、在岗状态、职称、受控年龄段或35岁以下标识、来源批次和更新时间。该表允许在数据未接入时为空，但不得生成演示人员或年龄，不向前端提供出生日期。

接口入口：

- `GET /api/admin/faculty/management-overview`：首页5项KPI、学院概览和优先课程。
- `GET /api/admin/faculty/management-kpis/{metric_key}/details`：5项KPI统一下钻，服务端校验指标白名单、学期、学院范围和分页参数。
- 课程、教师二级证据继续复用现有`management-course`、`management-teacher`接口。

正式工作量分配仍留待学校数据接入；本模块不把原型推导替代为正式人事统计，不实施人事评价、教师考核和自动调配。
