# 4.5 师资保障分析

> 现行模块说明，2026-09-19核对。首页、指标口径、下钻、权限与数据未接入状态均以本文和公共指标确认书为准。

## 1. 功能边界与目的

师资保障分析帮助教务处和学院判断课程是否过度依赖单个教师、重要课程的承担团队是否稳定、实际授课教师的职称与年龄结构是否具备分析证据，以及真实在岗人员数据是否足够。输出用于核查教学保障，不用于评价教师个人教学质量。

本模块不根据学生平均成绩给教师排名，不使用模拟年龄、学历、教龄或学缘形成正式结论。单一教师承担课程是需要核查的结构事实，不自动等同于教学质量差或教师能力不足。

## 2. 页面描述

页面先展示统计学期和当前授权范围，再直接展示5张可下钻KPI卡片，随后提供学院比较、优先课程、课程团队及教师教学经历。原首页业务边界提示、旧课程核查KPI、本期管理要点和证据就绪条不再单独占用首屏；相关公式、来源、规则版本和适用边界统一进入KPI tooltip及下钻工作台。

“学院授课师资保障概览”回答问题集中在哪里，并在学院列后展示课程总数；课程总数按可评估课程数与数据候选课程数之和计算。学院“课程师资情况”清单说明由哪些教师承担、影响多少选课人次，并以标签同时展示课程命中的全部核查类型、逐条展示全部核查原因；教师任务明细说明当前和历史承担情况。用户能够从汇总进入实际教学任务或团队证据，不能只有一个无法解释的风险分数。

首页指标为：

| 指标 | 业务含义与边界 |
| --- | --- |
| 授课教师总数/教职工总数 | 左侧显示当前条件和授权范围内教学任务涉及的授课教师去重人数；右侧显示当前学期同范围内正式在职教师去重人数，无数据时显示“—”。教职工总数优先使用真实人员学期快照；当前学期快照未接入时可读取正式教师主数据，但排除由导师、班主任或教学关系补出的占位人员；只有学期快照就绪时才计算人员口径参与率 |
| 教师结构异常课程数 | 命中以下任一或多项规则的课程按课程ID去重后计数，每门课程最多计1次：同一教师在最近最多3次实际开课中至少2次作为唯一授课教师（只有2次实际开课且均由同一教师唯一授课时也命中）；授课教师年龄全部大于等于55岁或全部小于等于55岁，年龄优先根据出生日期和当前日期计算；授课教师职称仅包含助教或讲师。年龄或职称证据不完整时不触发对应规则 |
| 连续单点授课教师数 | 同一教师在同一门课程最近3次实际开课中至少2次作为唯一授课教师，按教师工号去重；最近3次为实际开课记录，不是连续自然学期 |
| 高职称教师授课占比（教授、副教授） | 教授或副教授实际授课教师去重人数÷授课教师总数×100%；职称完整率低于90%不输出正式比例 |
| 青年教师授课占比（35岁以下） | 卡片主数值显示当前条件和授权范围内35岁以下青年授课教师去重人数，无数据时显示“—”；副文案显示授课教师去重总数，无数据时显示“—”。青年教师优先由后端根据出生日期和当前日期计算是否未满35岁，比例仍按青年教师数÷授课教师总数×100%计算，不使用模拟年龄 |

缺少联合授课分工比例时，不能把覆盖人数均分为正式教师工作量。

## 3. 核心流程

用户选择学期和授权范围后，可以点击任一KPI打开统一右侧下钻工作台。除“授课教师总数/教职工总数”外，工作台依次呈现指标值、公式、来源、适用边界、组织分布和服务端分页明细；URL使用`drill`参数保留当前指标。“授课教师总数/教职工总数”下钻简化为“授课教师名单”，不重复显示状态、指标卡、口径说明和名单说明，表格展示工号、姓名、部门、职称、学历、人员类别、授课课程数、教学班数及授课课程；部门与人员类别优先读取真实人员快照，快照未接入时用正式在职人员主数据和课程责任部门回补。学历只读取真实人员字段，没有真实字段时显示“—”，不得读取模拟学历；人员类别没有真实数据时显示“—”。教学班数按当前学期、当前授权范围内教师参与的有效教学任务记录计数。名单支持按姓名、工号、授课课程名称模糊查询和部门下拉筛选，默认按教学班数降序、授课课程数降序、姓名升序排列。高职称和青年教师指标按课程责任学院展示比例与证据覆盖率，并单列职称、年龄字段缺失治理清单；连续单点指标逐期展示最近3次实际开课的唯一教师证据。点击课程继续进入既有课程详情，点击教师进入教学经历，返回时保留首页学期和范围。

“教师结构异常课程数”下钻简化为“教师结构异常课程”，不显示状态标签、指标口径卡、结构分布和名单说明。表格展示课程号、课程名称、开课学院、课程性质、教学班数、学生人次、授课教师数、教授/副教授数及全部命中原因，不展示职称完整率；命中多条结构规则时使用同一单元格逐项完整展示。查询支持课程号、课程名称模糊匹配和开课学院下拉筛选，开课学院选项由当前授权范围内全部命中课程生成；默认按教学班数降序、课程号升序排列。

“连续单点授课教师数”下钻简化为“连续单点授课教师”，同样不显示状态标签、指标口径卡、结构分布和名单说明。表格按教师—课程证据展示工号、姓名、部门、职称、学历、人员类型、连续单点课程、命中证据、本期教学班和本期学生人次；人员属性优先使用真实人员快照或正式在职人员主数据，缺失时显示“—”，不读取模拟画像。查询支持工号、姓名、课程名称模糊匹配和部门筛选，部门选项由当前授权范围内命中教师生成；默认按本期教学班数降序、部门和姓名升序排列。

查看教师任务时，系统展示该教师实际承担的教学班和课程，而非仅显示累计数。由团队、教师再返回列表时保持原过滤条件。跨院比较可以提供聚合，但他院教师或学生明细仍按相应权限控制；学院用户仅因本院课程关系查看外院教师时，前端必须携带该课程证据编号，接口只返回该授权课程范围内的教学经历。

需要管理解释时，辅助分析应引用课程、教师及任务证据，说明单点承担和团队结构为什么值得核查；不能给出未经证实的人事调整结论。

## 4. 异常容错

没有当期教学任务时提示该范围缺少活动证据；教师或职称关系缺失时显示完整性边界，不推定课程无人承担。真实在岗人员快照未接入时，当前学期“教职工总数”后备读取正式在职教师主数据，无对应数据时显示“—”；“青年教师授课占比”仍显示为“—/待接入”。职称或年龄证据覆盖率低于90%时不输出正式比例。

查询或抽屉加载失败允许重试，主页面保留原条件。切换学期和学院后的旧请求不能覆盖新对象。没有明细权限时禁止通过URL、指标键或对象ID绕过。统一下钻接口只接受服务端白名单内的5个指标键。

核验时检查概览与下钻是否采用同一学期、学院、异常任务门禁和去重规则，名单或任务合计不能与上层指标矛盾；涉及人员组织口径和课程责任口径差异时必须说明。

## 5. 数据、接口与非目标

`dim_staff_employment_snapshot`承接学校真实人员学期快照，包括人员、组织、在岗状态、职称、出生日期、受控年龄段或35岁以下标识、来源批次和更新时间。青年标识优先在后端根据出生日期和当前日期计算；该表允许在数据未接入时为空，但不得生成演示人员或年龄，出生日期不向前端返回。

接口入口：

- `GET /api/admin/faculty/management-overview`：首页5项KPI、学院概览和优先课程。
- `GET /api/admin/faculty/management-kpis/{metric_key}/details`：5项KPI统一下钻，服务端校验指标白名单、学期、学院范围和分页参数；授课教师名单额外支持`keyword`和`department`，筛选及默认排序均在分页前完成。
- 课程、教师二级证据继续复用现有`management-course`、`management-teacher`接口。

正式工作量分配仍留待学校数据接入；本模块不把原型推导替代为正式人事统计，不实施人事评价、教师考核和自动调配。
