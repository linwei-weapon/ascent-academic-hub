# 4.5 师资保障分析

> 新增专项正文，2026-09-14。整合既有师资保障需求和当前页面职责，未修改计算、阈值或权限。

## 1. 功能边界与目的

师资保障分析帮助教务处和学院判断课程是否过度依赖单个教师、教学任务是否集中、重要课程的承担团队是否稳定，以及当前教师和职称证据是否足够。输出用于核查教学保障，不用于评价教师个人教学质量。

本模块不根据学生平均成绩给教师排名，不使用模拟年龄、学历、教龄或学缘形成正式结论。单一教师承担课程是需要核查的结构事实，不自动等同于教学质量差或教师能力不足。

## 2. 页面描述

页面先展示统计学期和当前授权范围，再提供保障概览、学院比较、课程团队及教师任务等分析。查看某学院或对象时，通过局部抽屉呈现明细，尽量保留总览和比较现场。

学院比较回答问题集中在哪里；课程清单说明由哪些教师承担、影响多少选课人次；教师任务明细说明当前和历史承担情况。用户能够从汇总进入实际教学任务或团队证据，不能只有一个无法解释的风险分数。

主要指标沿用现有正式定义：

| 指标 | 业务含义与边界 |
| --- | --- |
| 本科教学活跃教师 | 选定学期实际承担本科教学任务的去重教师 |
| 单一教师覆盖课程 | 当前任务仅关联一名实际授课教师的课程，需检查源关系完整性 |
| 高影响单点课程 | 单一教师覆盖且达到现有核查阈值的课程；原型阈值不是国家标准 |
| 教授本科教学参与率 | 教授参与本科教学的比例；分母是否具备完整岗位状态必须披露 |
| 职称证据完整率 | 实际授课教师中职称信息可用的比例，不等同于职称结构优劣 |
| 主讲任务集中度 | 现有主讲字段所覆盖的任务或选课人次集中程度，不等同于精确工时 |

缺少联合授课分工比例时，不能把覆盖人数均分为正式教师工作量。

## 3. 核心流程

用户选择学期和授权范围，查看概览后定位某学院或课程。打开课程团队证据时，看到实际关联教师、教学任务、职称信息、历史开课规模和需要确认的事项；切换对象只更新相关明细，不无意清空总览。

查看教师任务时，系统展示该教师实际承担的教学班和课程，而非仅显示累计数。由团队、教师再返回列表时保持原过滤条件。跨院比较可以提供聚合，但他院教师或学生明细仍按相应权限控制。

需要管理解释时，辅助分析应引用课程、教师及任务证据，说明单点承担和任务集中为什么值得核查；不能给出未经证实的人事调整结论。

## 4. 异常容错

没有当期教学任务时提示该范围缺少活动证据；教师或职称关系缺失时显示完整性边界，不推定课程无人承担。单点风险可能受多人授课关系是否完整影响，应提供核对来源。

查询或抽屉加载失败允许重试，主页面保留原条件。切换学期和学院后的旧请求不能覆盖新对象。没有明细权限时禁止通过 URL 或对象 ID 绕过。

核验时检查概览与课程清单是否采用同一学期、学院与去重规则，名单或任务合计不能与上层指标矛盾；涉及不同统计粒度时必须说明。

## 5. 后续与非目标说明

正式工作量分配、教师岗位和在岗状态等来源不足的部分，留待学校数据接入；本文件不把原型推导替代为正式人事统计。不实施人事评价、教师考核和自动调配。
