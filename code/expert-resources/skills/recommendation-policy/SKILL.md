# 推免年度规则核对

应用资源版本：2.0.0。来源为资源目录种子；实际发布状态、固定依赖和运行记录由系统管理。

## 适用任务

整理推免条件、排名、材料与规则影响所需的年度证据；条件未具备时阻止资格计算。

## 执行说明

任务：整理推免条件、排名、材料与规则影响所需的年度证据；条件未具备时阻止资格计算。
先核对当前身份、对象与可用证据。
1. 确认拟讨论年度、学校规则与学院细则的适用关系。
2. 逐项登记已批准规则、版本、范围、条款及认定责任来源。
3. 核对课程、成绩、权重、排名全集、并列、名额和例外处理是否齐备。
4. 当前缺少年度资料时输出具体缺项及补充顺序；资料补齐后需新增适配器、样例测试和业务确认才能开放。
回答顺序：当前可确认的事实 → 对管理问题的含义 → 不能确认的内容 → 最小下一步。只引用本轮工具返回的证据，不补写学校政策或业务数据。

## 输入

输入契约见 [input.schema.json](input.schema.json)。对象ID从当前身份的选项取得，不能用专业名称或示例标记直接调用。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `college_id` | 否 | 当前身份授权范围内的学院ID；不传不代表获得全校权限。 |

## 工作步骤

1. 确认本轮要回答的问题与当前身份范围；需要对象时调用 list_analysis_options。
2. 校验所需对象和证据，范围冲突或关键资料缺失时停止相应计算并列出具体缺项。
3. 确认拟讨论年度、学校规则与学院细则的适用关系。
4. 逐项登记已批准规则、版本、范围、条款及认定责任来源。
5. 核对课程、成绩、权重、排名全集、并列、名额和例外处理是否齐备。
6. 当前缺少年度资料时输出具体缺项及补充顺序；资料补齐后需新增适配器、样例测试和业务确认才能开放。
7. 按输出契约保存结果、来源、限制及待明确事项；发布版本与运行时实际版本分别记录。

## 计算与解释规则

- 每次调用使用服务端当前工作身份校验范围；参数不能扩大学院范围，不返回个人身份信息。
- 先读取可选对象，再使用真实ID查询；输入不完整时只追问影响本轮计算的关键项。
- 只消费学校数据，既不回写学校主数据，也不执行开班、录取、课程认定或资格审批。
- 正式事实、管理者补充和讨论假设分开表达；口头补充不能覆盖已保存的来源事实。
- 未知、未映射、零记录和数值0分别表达；缺失对象不得被静默排除以制造完整结果。
- 输出实际范围、来源和观察时间；只有同对象、同规则且可复核的数据才能比较。历史批次不稳定时不补造趋势。
- 工具运行完成仅说明执行状态；需经人工检查数字、范围、边界后才可确认业务结果。
- 通用经验、往年办法和管理者口头假设不能替代当年度正式政策。
- 排名必须使用同一规则下完整且授权的群体，不在局部名单上补算正式名次。
- 校内推免资格与目标院校接收要求分别核对，不能合并为保研成功判断。
- 规则讨论与现行规则分开，讨论参数不能写回或替代已批准版本。

## 输出

输出契约见 [output.schema.json](output.schema.json)。status=blocked；data 只允许表示资料准备和检查项，返回 missingEvidence，不生成资格、排名、名额等业务结果。

用户阅读顺序：范围与本轮判断 → 实际数据与证据表 → 限制与待补资料 → 可以继续的问题。运行成功与人工确认分开。

## 已知边界

- R1—R5 均未达到年度业务执行条件；仅交付规则检查契约和缺项清单。
- 不生成资格名单、完整准备率、分数排名、名额变化或录取概率。
- 接收要求辅助能力尚需目标院校/专业的有效规则。

## 所需证据

- 当年度已批准的学校推免办法、学院实施细则及其生效版本
- 适用群体、名额分配及毕业/学位/纪律等相关条件来源
- 课程范围、有效成绩、权重、排名全集、并列及例外处理规则
- 年度材料清单、认定状态及有效期；接收院校要求需单独核对

## 当前固定缺项

- 当年度已批准的学校推免办法、学院实施细则及其生效版本
- 适用群体、名额分配及毕业/学位/纪律等相关条件来源
- 课程范围、有效成绩、权重、排名全集、并列及例外处理规则
- 年度材料清单、认定状态及有效期；接收院校要求需单独核对

## 工具依赖

当前处理器为 `unavailable`。没有可执行业务工具，不允许修改状态绕过证据要求。

## 案例与发布检查

案例见 [examples/cases.json](examples/cases.json)。`${selected_*}` 为需由真实选项替换的输入标记，预期值是核验条件，不是虚构的学校结果。使用同一版本真实运行，核对参数、数据范围、来源、限制及输出结构后才可提交人工确认；确认后按系统规则发布。
